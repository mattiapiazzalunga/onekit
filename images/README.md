# OneKit artwork

The public core uses the same official cube as the OneKit webapp.

- `logo.svg`: scalable logo, copied from the webapp's `images/logo.svg`.
- `logo.png`: 512 by 512 PNG, copied from the webapp's `images/app-512.png`.

The README displays the PNG at 112 by 112 pixels, centered above the project
name. Its absolute public URL also works outside GitHub, including package
README renderers. These local copies keep the core independent of the private
webapp repository.
