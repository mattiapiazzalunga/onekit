# TXT to JSON

Command: `onekit run txt-to-json`. Use `onekit run --help` for input and output arguments.

Category: **converters**.
Fidelity: **exact**. Requires valid JSON already contained in the TXT file. Validates and formats the data; arbitrary prose is not converted into an invented JSON schema.

Accepted types: `txt`. Output type: `json`.
Accepts multiple inputs: **no**.

Input validation: **encoded-text**. Required file count: **1–1**.
CLI: **8,388,608 bytes per file**, **134,217,728 bytes total**.
Content checks run before processing. Renaming a file does not change its actual format.

Options: `source_encoding`.

Python packages: standard library or external engine.
External engines: see the developer engine matrix for language adapters.

Processing implementation: [shared family adapter](../../../src/onekit/tools/text_converters.py).
Contracts and regression fixtures: [tests](../../../tests/test_core.py).
