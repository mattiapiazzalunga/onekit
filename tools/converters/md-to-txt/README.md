# Markdown to TXT

Command: `onekit run md-to-txt`. Use `onekit run --help` for input and output arguments.

Category: **converters**.
Fidelity: **compromise**. Extracts readable Markdown text, removing markup. Headings, lists and tables lose formatting; images and scripts are not exported.

Accepted types: `md`. Output type: `txt`.
Accepts multiple inputs: **no**.

Input validation: **text**. Required file count: **1–1**.
CLI: **8,388,608 bytes per file**, **134,217,728 bytes total**.
Content checks run before processing. Renaming a file does not change its actual format.

Options: none.

Python packages: markdown-it-py.
External engines: see the developer engine matrix for language adapters.
