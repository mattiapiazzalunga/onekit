# Contributing

Help build OneKit's open revolution: everyday tools for everyone, from hands-on tasks to workflows run by local AI agents. Contribute to make tools more efficient and effective: improve speed and memory use, fix incorrect results, add regression examples, or clarify documentation and agent workflows.

Find work in [GitHub issues](https://github.com/mattiapiazzalunga/onekit/issues) and the [website request board](https://onekit.org/requests/). Discuss contract changes and large dependencies before implementation.

Keep Artifact/Result independent of CLI/HTTP/storage. Prefer small optional dependencies and lazy imports. Never evaluate user code merely to validate it. Use argument arrays, no shell execution and bounded native timeouts. Document compromise behavior honestly. Update catalog, tool directories, guides and locks together.

Preserve original and third-party notices. New original files carry `Copyright 2026 Mattia Piazzalunga` and `SPDX-License-Identifier: LicenseRef-PolyForm-Shield-1.0.0`. Contributions use PolyForm-Shield-1.0.0. Record appropriate attribution without claiming upstream ownership. Do not commit credentials, private files, virtual environments or dependency directories.

Contribute original code under PolyForm Shield 1.0.0 only when you have the necessary rights. Preserve third-party terms and identify any separately licensed material.
