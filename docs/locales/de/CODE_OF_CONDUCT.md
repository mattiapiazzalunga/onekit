# Verhaltenskodex

Begrüße Mitwirkende unabhängig von Hintergrund, Identität, Erfahrung oder Fähigkeit. Sei respektvoll und halten Sie Kritik auf die Arbeit fokussiert. Geben Sie konstruktives, umsetzbares Feedback.

Belästigung, Drohungen, Diskriminierung, Doxxing, Offenlegung privater Informationen, sexualisierte Aufmerksamkeit und anhaltende Störungen sind in Projektbereichen nicht akzeptabel. Bedenken privat an `hello@mattiapiazzalunga.com` melden.

Betreuer behandeln Meldungen diskret und wenden angemessene Klarstellungen, Warnungen, Inhaltsentfernungen, vorübergehende Beschränkungen oder Ausschlussmaßnahmen an. Vergeltung ist inakzeptabel. Betreuer folgen denselben Standards und legen Interessenkonflikte offen, wenn sie Meldungen bearbeiten.
