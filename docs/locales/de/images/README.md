# OneKit Artwork

Offizielle OneKit-Würfelgrafiken, die vom öffentlichen Kern verwendet werden.

- `logo.svg`: skalierbares Logo.
- `logo.png`: 512 durch 512 PNG.

Der README zeigt den PNG mit 112 mal 112 Pixeln, zentriert über dem Projektnamen. Seine absolute öffentliche URL funktioniert auch außerhalb von GitHub, einschließlich Paket README Renderer.
