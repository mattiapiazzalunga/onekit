# Арт OneKit

Официальные кубические изображения OneKit, используемые публичным ядром.

- `logo.svg`: масштабируемый логотип.
- `logo.png`: 512 от 512 PNG.

README отображает PNG на 112 пикселей по 112, по центру над названием проекта. Его абсолютный публичный URL также работает за пределами GitHub, включая пакетные рендереры README.
