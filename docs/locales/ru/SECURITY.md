# Политика безопасности

Сообщайте уязвимости напрямую `security@onekit.org`, указывая версию, платформу, инструмент, версии зависимостей, влияние и синтетическое воспроизведение. Не публикуйте чувствительные файлы, учетные данные или готовые к эксплуатации приватные отчеты на публичных трекерах. Исправления нацелены на последнюю стабильную версию; времени ответа не гарантируется.

Ядро ограничивает пути, размеры входных данных, распаковку архивов, число пикселей, сравнения и конвейеры. Для шифрования используется аутентифицированный AES-256-GCM с новыми солью и nonce, а также scrypt; потерянные пароли восстановить невозможно. Существующие выходные файлы по умолчанию сохраняются. Проверка Python разбирает исходный код без его выполнения.

Внешние конвертеры/компиляторы — это отдельные нативные программы, а не полноценная песочница. Держите их в актуальном состоянии и изолируйте враждебные документы с помощью средств ОС. CLI не является неаутентифицированной службой удалённого конвертирования. Редактирование подписанного PDF может аннулировать подписи; права PDF не равны целостности шифрования.

Обычные проверки никогда не должны получать секреты публикации. Стабильные теги отмечают проверенные защищённые основные коммиты. Сбой зависимости, лицензии или безопасности блокирует публикацию. Ни один набор тестов не гарантирует защиту от всех некорректных входных данных или атак.
