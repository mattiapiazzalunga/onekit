# Сравнить файлы JSON

Команда: `onekit run diff-json`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Сравнение**. Точность: **точная**. Сравнение ноутбука может включать Markdown, код или оба варианта. Текстовый режим LaTeX пропускает команды.

Допустимые типы: `json, txt`. Тип вывода: `json`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **текст**. Требуемое количество файлов: **2–2**. CLI: **8 388 608 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/diff/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
