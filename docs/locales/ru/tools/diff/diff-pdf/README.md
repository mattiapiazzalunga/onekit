# Сравните файлы PDF

Команда: `onekit run diff-pdf`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Сравнение**. Точность: **с ограничениями**. Сравнивается извлечённый текст, а не визуальное оформление.

Допустимые типы: `pdf`. Тип вывода: `json`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **2–2**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: pycryptodome, pypdf. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/diff/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
