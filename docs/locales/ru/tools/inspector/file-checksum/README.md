# Вычислить контрольную сумму

Команда: `onekit run file-checksum`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Анализ**. Точность: **точная**. Вычисляет SHA-256, SHA-512, SHA-1 или MD5 локально. При желании можно сравнить с ожидаемой контрольной суммой для одного файла. Контрольная сумма не проверяет цифровую подпись и не гарантирует безопасность файла.

Допустимые типы: `*`. Тип вывода: `json`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–20**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `algorithm`, `expected`.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/file_checksum.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
