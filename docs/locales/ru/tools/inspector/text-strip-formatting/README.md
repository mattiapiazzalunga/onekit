# Убрать форматирование текста

Команда: `onekit run text-strip-formatting`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Анализ**. Точность: **с ограничениями**. Преобразуйте вставленный текст, UTF-8/UTF-16 текстовые файлы, HTML, Markdown или Word DOCX основной текст в локальный файл UTF-8 TXT. Убирает стили, ссылки и разметку, сохраняя читаемый текст и базовые разрывы абзацев/таблиц. Простой текст сохраняет буквальные знаки препинания. Нет OCR; заголовки, нижние колонтитулы, изображения и комментарии DOCX опущены. До 8 MiB на ввод.

Допустимые типы: `txt, html, md, docx`. Тип вывода: `txt`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–1**. CLI: **8 388 608 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `input_format`.

Пакеты Python: markdown-it-py, defusedxml. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/plain_text.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
