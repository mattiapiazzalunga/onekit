# Инспектор URL

Команда: `onekit run url-inspect`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Анализ**. Точность: **с ограничениями**. Проверяйте компоненты URL, статус HTTP, финальный URL и доступные заголовки ответов прямо с вашего устройства. Регистрирует до 10 перенаправлений HTTP. Сетевые сбои оставляют частичный отчет. Это не проверка на фишинг или вредоносное ПО, не проверка DNS и не проверка права собственности.

Допустимые типы: `txt`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **16 384 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/link_tools.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
