# Удалить метаданные

Команда: `onekit run file-metadata-remove`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Анализ**. Точность: **точная**. Сохраняет выбранное содержимое; проверяйте важные результаты.

Допустимые типы: `*`. Тип вывода: `*`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: exiftool.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/inspector/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
