# Генератор цветовой палитры

Команда: `onekit run color-palette`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Дизайн**. Точность: **точная**. Палитры OKLCH из пяти цветов с уменьшением цветности для соответствия пространству sRGB и расчётом контраста текста по WCAG. Правила гармонии — это дизайнерские эвристики, а не гарантия доступности.

Допустимые типы: `txt`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **128 байт на файл**, **1 048 576 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `harmony`, `lightness`, `chroma`, `hue`, `format`.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/design.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
