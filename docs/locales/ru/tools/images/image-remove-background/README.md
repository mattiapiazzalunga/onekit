# Удалить фон изображения

Команда: `onekit run image-remove-background`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Изображения**. Точность: **с ограничениями**. Локально удаляет фон и экспортирует прозрачный PNG. Использует U2Net. Тонкие края могут потребовать проверки. Модель загружается при первом использовании.

Допустимые типы: `png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: onnxruntime, numpy, pooch, Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/background.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
