# Повернуть и отразить изображение

Команда: `onekit run image-rotate-flip`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Изображения**. Точность: **точная**. Примените ориентацию EXIF, повернув по часовой стрелке на 0, 90, 180 или 270 градусов, затем отразите по горизонтали, вертикали или оба. Экспортирует PNG без метаданных, сохраняя декодированные пиксели и прозрачность. Только изображения с одним кадром; до 40 миллионов пикселей.

Допустимые типы: `png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `angle`, `flip`.

Пакеты Python: Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/image_transform.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).
