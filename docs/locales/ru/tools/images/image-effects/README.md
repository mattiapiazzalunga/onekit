# Размытие, пикселизация и эффекты изображений

Команда: `onekit run image-effects`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Изображения**. Точность: **с ограничениями**. Размытие, пикселизация, усредняющее размытие, сплошное покрытие или градация серого в одном инструменте. Применяйте ко всему изображению или выбранным областям, с регулируемой интенсивностью и новым экспортом PNG. Размытие и пикселизация не гарантируют постоянное удаление конфиденциальных деталей. Только однокадровые изображения.

Допустимые типы: `png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `effect`, `scope`, `strength`, `color`, `regions`.

Пакеты Python: Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/image_effects.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
