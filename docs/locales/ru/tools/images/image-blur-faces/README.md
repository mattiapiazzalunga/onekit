# Автоматическое размытие лиц

Команда: `onekit run image-blur-faces`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **изображения**. Точность: **с ограничениями**. Обнаруживает лица локально с помощью YuNet и размывает их в новом PNG. Перед публикацией проверьте каждое лицо: автоматическое обнаружение может пропускать лица, а размытие не гарантирует анонимность. Только однокадровые изображения размером до 16 миллионов пикселей.

Допустимые типы: `png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: onnxruntime, numpy, Pillow. Внешние движки: адаптеры языков приведены в матрице движков для разработчиков.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/face_blur.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
