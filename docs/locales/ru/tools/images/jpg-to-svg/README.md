# JPG в SVG

Команда: `onekit run jpg-to-svg`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Изображения**. Точность: **с ограничениями**. Создает реальные векторные пути на основе палитры, соединяя цветные тайлы без встраивания растрового изображения. Фотографии становятся постеризованными; кривые контуры и тонкие градиенты приближаются. Лучше всего для простых плоских рисунков.

Допустимые типы: `jpeg`. Тип вывода: `svg`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `colors`, `resolution`.

Пакеты Python: Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/photo_tools.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
