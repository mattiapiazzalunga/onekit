# Преобразовать изображение в favicon

Команда: `onekit run image-to-favicon`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Изображения**. Точность: **с ограничениями**. Изменяет размер первого кадра изображения до квадратных иконок. Fit сохраняет всё изображение с прозрачными полями; fill обрезает края. Оригинальные файлы остаются без изменений.

Допустимые типы: `png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `*`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **67 108 864 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `format`, `fit`.

Пакеты Python: Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/favicon.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
