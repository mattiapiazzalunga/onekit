# OCR в PDF

Команда: `onekit run ocr-to-pdf`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **OCR**. Точность: **с ограничениями**. Распознавание зависит от качества сканирования и установленных языковых пакетов. Уравнения и оформление могут потребовать ручной правки.

Допустимые типы: `pdf, png, jpeg, webp, gif, bmp, tiff, ico`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `language`, `dpi`.

Пакеты Python: pytesseract, Pillow, pypdfium2, pypdf, pycryptodome. Внешние движки: tesseract.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/ocr/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
