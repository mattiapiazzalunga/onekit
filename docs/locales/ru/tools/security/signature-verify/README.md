# Проверить цифровую подпись

Команда: `onekit run signature-verify`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Безопасность**. Точность: **точная**. Офлайн-криптографическая проверка подписей PDF и CMS/P7M/P7S с использованием встроенных сертификатов. Для отдельных подписей нужен исходный файл. Цепочки доверия, отзыв, статус квалифицированной подписи и доверенные метки времени не проверяются.

Допустимые типы: `*`. Тип вывода: `json`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–2**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: pypdf, asn1crypto, pycryptodome. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/signatures.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
