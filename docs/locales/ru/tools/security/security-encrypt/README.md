# Шифруйте файлы или папки

Команда: `onekit run security-encrypt`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Безопасность**. Точность: **точная**. AES-256 зашифрован ZIP, совместим с 7-Zip. Имена файлов остаются видимыми. Потеря пароля делает восстановление невозможным.

Допустимые типы: `*`. Тип вывода: `zip`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–256**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `password`.

Пакеты Python: pycryptodome, stream-zip, stream-unzip. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/security/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
