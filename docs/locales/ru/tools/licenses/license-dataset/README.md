# Проверка лицензии набора данных

Команда: `onekit run license-dataset`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Лицензии**. Точность: **с ограничениями**. Оценка основана на декларациях и метаданных, а не на сертификате права или юридическом разрешении. Проверяйте каждое открытие с исходным источником и правообладателем. Отсутствие информации никогда не означает, что использование разрешено. Авторы и правообладатели могут различаться. Файлы анализируются локально; ссылки загружаются напрямую с их источника. Архивы ограничены и сканирование может быть неполным.

Допустимые типы: `csv, json, jsonld, txt, md, license, `. Тип вывода: `json`. Допускает несколько входных файлов: **да**.

Проверка входных данных: **любой тип файла**. Требуемое количество файлов: **1–256**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `ref`.

Пакеты Python: license-expression, defusedxml. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/license_check.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
