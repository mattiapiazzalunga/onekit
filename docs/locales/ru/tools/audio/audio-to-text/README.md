# Аудио в текст

Команда: `onekit run audio-to-text`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Аудио**. Точность: **с ограничениями**. Преобразует локально с Whisper tiny (многоязычный). Модель скачивается при первом использовании; аудио не загружается. Распознавание может ошибаться.

Допустимые типы: `mp3, wav, flac, ogg, aac, m4a, mp4, aif, aiff, opus, wma`. Тип вывода: `txt`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `language`.

Пакеты Python: faster-whisper. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/transcription.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
