# Скачать видео

Команда: `onekit run video-download`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Видео**. Точность: **точная**. Загрузки с YouTube и других сайтов yt-dlp, до 128 MiB. Поддержка сайтов различается; требуется подключение к интернету.

Допустимые типы: `txt`. Тип вывода: `*`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **16 384 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `quality`, `cookies`, `cookies_from_browser`, `format_id`, `referer`, `list_formats`.

Пакеты Python: yt-dlp. Внешние движки: ffmpeg.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/video_download.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
