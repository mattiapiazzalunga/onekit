# Изменить скорость видео

Команда: `onekit run video-speed`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Видео**. Точность: **с ограничениями**. Обрабатывается локально с FFmpeg. Повторное кодирование может привести к потере качества. Вывод GIF без звука.

Допустимые типы: `mp4, webm, mkv, mov, avi, gif, mpeg, mpg, m4v, ogv, ts`. Тип вывода: `mp4`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `speed`.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: ffmpeg, ffprobe.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/video_edit.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
