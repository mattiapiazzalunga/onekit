# Тестер регулярных выражений

Команда: `onekit run dev-regex-test`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Разработка**. Точность: **точная**. Тестирует регулярные выражения JavaScript локально с захватами, именованными группами, UTF-16 позициями и заменой. До 128 KiB текста, 1000 совпадений и 1 MiB выходных данных. Выполнение ограничено по времени; CLI требует Node.js.

Допустимые типы: `txt`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **131 072 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `pattern`, `flags`, `max_matches`, `enable_replacement`, `replacement`.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: node.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/regex_tester.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
