# Добавить водяной знак к PDF

Команда: `onekit run pdf-watermark`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **PDF**. Точность: **точная**. Добавляет текст или водяной знак в виде изображения PNG/JPEG на все или выбранные страницы, сохраняя исходные текст и графику. Поддерживает текст на западноевропейском языке, одиночное или повторяющееся расположение, вращение и непрозрачность. Исходный файл не изменяется.

Допустимые типы: `pdf`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `text`, `pages`, `font`, `font_size`, `color`, `opacity`, `angle`, `position`, `layout`, `margin`, `watermark_type`, `image_base64`, `image_width`.

Пакеты Python: pypdf, reportlab, Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/pdf.watermark/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
