# Удалить водяной знак PDF

Команда: `onekit run pdf-remove-watermark`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **PDF**. Точность: **с ограничениями**. Просматривайте и удаляйте выбранный текст, изображения и вызовы Form XObject, включая вложенные Form XObject и текст, закодированный с помощью шрифтов. Помеченные артефакты водяных знаков и аннотации водяных знаков удаляются автоматически. Непомеченные объекты требуют выбора или точного текста; знаки, встроенные в пиксели, нельзя отделить от изображения. Проверьте каждую страницу.

Допустимые типы: `pdf`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `text`, `mode`, `objects`.

Пакеты Python: pypdf. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/pdf_design.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).
