# Проверить PDF/UA

Командир: `onekit run pdf-validate-pdfua`. Используйте `onekit run --help` для входных и выходных аргументов.

Категория: **pdf** Верность: **точная **. Проверьте PDF/UA-1 автоматически с помощью местного двигателя проверки. Проходящий результат по-прежнему требует ручного обзора доступности. Отчет идентифицирует движок, профиль и точный хэш файла.

Допустимые типы: `pdf`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `profile`.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [ совместно используемых семейных адаптеров ](../../../../../../src/onekit/tools/pdf_conformance.py). Контракты и регрессионные приспособления: [tests](../../../../../../tests/test_core.py). Настройка двигателя и лицензии: [engine guide](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
