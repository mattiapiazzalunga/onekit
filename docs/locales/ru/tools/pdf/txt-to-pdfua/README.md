# Текст в PDF/UA

Командир: `onekit run txt-to-pdfua`. Используйте `onekit run --help` для входных и выходных аргументов.

Категория: **pdf** Верность: **точная **. Создайте тег PDF/UA-1 из простого текста с заголовком и языком. Отдельные абзацы с белыми линиями. Только латинские шрифты; обзор порядка чтения и значения. Автоматические проверки не заменяют ручной обзор доступности.

Допустимые типы: `txt`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Вводная валидация: **text**. Требуемое количество файлов: **1-1**. CLI: **262 144 байта на файл **, **8 388 608 байтов всего **. Проверки контента выполняются перед обработкой. Переименование файла не изменяет его фактического формата.

Варианты: `title`, `language`.

Python упаковок: reportlab, pypdf, Pillow. Внешние движки: см. матрицу движка разработчика для языковых адаптеров.

Реализация обработки: [ совместно используемых семейных адаптеров ](../../../../../../src/onekit/tools/pdfua.py). Контракты и регрессионные приспособления: [tests](../../../../../../tests/test_core.py). Настройка двигателя и лицензии: [engine guide](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
