# Необратимое скрытие данных в PDF

Команда: `onekit run pdf-redact`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **PDF**. Точность: **с ограничениями**. Необратимо скрывает выбранные области и пересоздаёт каждую страницу из растровых пикселей. Исходный текст, вложения, комментарии, формы и метаданные не копируются; возможность выделять текст и векторное качество теряются. Исходный файл остаётся без изменений.

Допустимые типы: `pdf`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `regions`, `dpi`.

Пакеты Python: pypdfium2, Pillow, reportlab, pypdf. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/redaction.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
