# Создать заполняемый PDF

Команда: `onekit run pdf-make-fillable`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **PDF**. Точность: **точная**. Добавьте именованные текстовые поля AcroForm, флажки и варианты выпадающих списков, используя прямоугольники с нормализованными координатами относительно верхнего левого угла. Сохраняет существующие поля и содержимое страниц. Нет автоматического обнаружения пустых полей и конверсии XFA; проверьте совместимость с ридером.

Допустимые типы: `pdf`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `fields`.

Пакеты Python: pypdf. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/pdf_design.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
