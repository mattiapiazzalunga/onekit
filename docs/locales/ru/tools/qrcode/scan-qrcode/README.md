# Сканирование кода QR

Команда: `onekit run scan-qrcode`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **QR-коды**. Точность: **точная**. Локальное чтение полезной нагрузки QR из изображения; обратное декодирование показывает сохранённое содержимое, а не исходное изображение или настройки генератора. Ссылки автоматически не открываются.

Допустимые типы: `png, jpeg, webp, bmp, gif`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **16 777 216 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: Pillow, zxing-cpp. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/qrcode.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
