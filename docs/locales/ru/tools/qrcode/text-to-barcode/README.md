# Создайте штрихкод

Команда: `onekit run text-to-barcode`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **QR-коды**. Точность: **точная**. Локально генерирует код 128, код 39, EAN-13, EAN-8, UPC-A, ITF и ISBN-13. Контрольные цифры для розницы проверены или рассчитаны; идентификаторы не зарегистрированы и не назначены OneKit.

Допустимые типы: `txt`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **1 024 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `barcode_type`, `format`, `module_width`, `height`, `quiet_zone`, `show_text`, `font_size`, `dpi`.

Пакеты Python: python-barcode, Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/barcode.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
