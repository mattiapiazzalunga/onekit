# GIF в изображения

Команда: `onekit run gif-to-images`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **с ограничениями**. Экспортирует каждый кадр GIF как составное изображение PNG с учётом режима удаления кадров и прозрачности. До 120 кадров и 40 миллионов пикселей суммарно. Длительности кадров указаны в подробностях результата.

Допустимые типы: `gif`. Тип вывода: `png`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/image_frames.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
