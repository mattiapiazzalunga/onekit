# Таблицы PDF в CSV

Команда: `onekit run pdf-tables-to-csv`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **с ограничениями**. Обнаруживает таблицы из выровненного выделяемого текста. Для сканированных документов требуется OCR; сложные макеты, объединенные ячейки и выравнивание колонок требуют проверки. Excel использует один лист на таблицу; CSV экспортирует один файл на таблицу.

Допустимые типы: `pdf`. Тип вывода: `csv`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `pages`.

Пакеты Python: pycryptodome, pypdf. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/pdf_tables.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
