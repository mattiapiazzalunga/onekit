# JSON в TXT

Команда: `onekit run json-to-txt`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **точная**. Проверяет и форматирует JSON как UTF-8 TXT, сохраняя его структуру данных, а не преобразуя значения в текст.

Допустимые типы: `json`. Тип вывода: `txt`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **8 388 608 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: стандартная библиотека или внешний движок. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/text_converters.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
