# YAML в JSON

Команда: `onekit run yaml-to-json`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **точная**. Таблицы XML используют повторяющиеся плоские записи. Преобразование JSON в XML сохраняет типы с помощью типизированной схемы корневого элемента и элементов записей; атрибуты XML используют @, а текст использует #text в JSON. Формулы в таблицах не вычисляются; по умолчанию используется первый лист. Проверьте схему и значения после конверсии.

Допустимые типы: `yaml`. Тип вывода: `json`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст**. Требуемое количество файлов: **1–1**. CLI: **8 388 608 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Варианты: нет.

Пакеты Python: PyYAML. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/structured_data.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
