# TXT в PDF

Команда: `onekit run txt-to-pdf`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **с ограничениями**. Создает PDF с базовым форматированием абзацев из обычного текста. Исходные разрывы строк TXT превращаются в абзацы; неподдерживаемые символы или чрезмерное количество страниц будут зафиксированы.

Допустимые типы: `txt`. Тип вывода: `pdf`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **текст в выбранной кодировке**. Требуемое количество файлов: **1–1**. CLI: **8 388 608 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `source_encoding`.

Пакеты Python: reportlab, Pillow. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/text_converters.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
