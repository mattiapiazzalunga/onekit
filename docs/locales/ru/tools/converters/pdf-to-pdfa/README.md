# PDF в PDF/A

Команда: `onekit run pdf-to-pdfa`. Сведения об аргументах ввода и вывода доступны через `onekit run --help`.

Категория: **Конвертеры**. Точность: **с ограничениями**. Преобразуйте файл локально в PDF/A-2b или 3b со встроенными шрифтами. Перед скачиванием проверяется фактически созданный файл. Неподдерживаемое содержимое может быть удалено или отклонено; проверьте результат.

Допустимые типы: `pdf`. Тип вывода: `pdfa`. Допускает несколько входных файлов: **нет**.

Проверка входных данных: **по типу файла**. Требуемое количество файлов: **1–1**. CLI: **134 217 728 байт на файл**, **134 217 728 байт всего**. Содержимое проверяется до обработки. Переименование файла не меняет его фактический формат.

Параметры: `icc_profile`, `profile`.

Пакеты Python: pdftopdfa, pikepdf, jsonschema, fonttools, pdfminer.six. Внешние движки: адаптеры языков программирования перечислены в матрице движков для инструментов разработчика.

Реализация обработки: [общий адаптер семейства инструментов](../../../../../../src/onekit/tools/converters/__init__.py). Контракты и данные для регрессионных тестов: [тесты](../../../../../../tests/test_core.py). Настройка движков и лицензии: [руководство по движкам](../../../docs/engines.md).

Эта папка сгенерирована из общего каталога `python scripts/tool_docs.py`. Отредактируйте реестр и адаптер семейства, добавьте тестовые данные для регрессионных тестов, затем заново сгенерируйте папку.
