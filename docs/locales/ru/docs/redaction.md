# Необратимое скрытие данных

<a id="pdf"></a>
## PDF

Каждая страница рендерится, выбранные пиксели заменяются на непрозрачный черный цвет, и создается новый PDF из изображений с уже скрытыми конфиденциальными областями. Ни один оригинальный объект PDF не копируется. Это удаляет оригинальный выбираемый текст, слои OCR, скрытые слои, поля форм, объекты аннотаций/комментариев, ссылки, скрипты, вложения, метаданные, миниатюры и историю пошагового сохранения из выходного файла. Видимые аннотации объединяются в пиксели, чтобы существующая непрозрачная аннотация случайно не раскрыла покрытое содержимое. Проверьте предварительный просмотр для различий в отображении полей/аннотаций; интерактивные объекты не сохраняются. Невыбранное видимое содержимое страницы остается в виде пикселей.

<a id="images"></a>
## Images

Перед кодированием нового непрозрачного RGB PNG пиксели заменяются на сплошной черный цвет. В кодированных областях нет съёмного наложения, оригинального слоя или исходных непокрытых пиксельных данных. Исходные EXIF, GPS, XMP, комментарии, профили, миниатюры и другие оригинальные метаданные не копируются. Прозрачность накладывается на белый, скрытые RGB значения под прозрачными пикселями отбрасываются. Ориентация EXIF применяется перед интерпретацией областей. Анимированные и многокадровые входные данные отклоняются, чтобы дополнительные кадры не оставались с незакрытыми конфиденциальными областями; сначала экспортируйте один кадр.

<a id="cli-and-workflows"></a>
## CLI and workflows

Установите `onekit-tools[pdf]` для необратимого скрытия данных в PDF или `onekit-tools[images]` для изображений. Оба инструмента принимают `regions` — массив прямоугольников, при желании сериализованный как строка JSON. Каждый прямоугольник имеет `page` (начинается с единицы, по умолчанию 1), `x`, `y`, `width`, `height`. Координаты — это доли визуально ориентированной страницы/изображения с началом в верхнем левом углу: `0.1` означает 10%. Для изображений `page` должен быть 1. Можно выбрать до 500 прямоугольников. Границы должны помещаться внутри страницы; границы масок округляются наружу и расширяются на один пиксель выходного изображения, чтобы закрыть и дробные участки краёв.

```sh
onekit run pdf-redact private.pdf -o redacted.pdf --options '{"regions":[{"page":1,"x":0.1,"y":0.2,"width":0.5,"height":0.1}],"dpi":200}'
onekit run image-redact private.jpg -o redacted.png --options '{"regions":[{"x":0.2,"y":0.2,"width":0.3,"height":0.2}]}'
```
