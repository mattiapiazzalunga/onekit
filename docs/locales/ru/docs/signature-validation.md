# Проверка цифровых подписей

CLI и браузер используют один движок проверки Python. Документы не загружаются на сервер. Проверяются подписи и сроки действия доверенных списков ЕС; неподдерживаемые службы исключаются.

Криптографическая целостность и проверка AdES — отдельные результаты. Проверка использует локальные доказательства и аутентифицированные доверенные списки ЕС. При отсутствии доказательств результат неопределён. Эквивалентность DSS не сертифицирована.

Локально проверяет подписи PDF и CMS с валидацией AdES. Для отделённых подписей нужен исходный файл. Можно добавить один ZIP с данными проверки подписи. При отсутствии доказательств доверия или отзыва результат неопределён.

Обновите общедоступные доверенные списки этой командой. Она не отправляет документы или данные подписантов.

```sh
python -m pip install "onekit-tools[verification,trustlists]"
python -m onekit.signature_evidence eu-trust-lists.zip
onekit run signature-verify signed.pdf eu-trust-lists.zip -o report
```

Манифест ZIP с данными проверки использует следующую структуру. Дополнительные сертификаты не становятся произвольными якорями доверия.

```json
{"schema":"onekit-signature-evidence-v1","lotl":"lotl.xml","trusted_lists":[{"url":"https://official.example/list.xml","path":"tl/list.xml"}],"certificates":[],"crls":[],"ocsps":[]}
```

Нативному Python для Windows ARM64 могут понадобиться инструменты сборки cryptography. Если бинарный wheel недоступен, используйте Python x64.

Текущий снимок содержит 30 территорий. Поддерживаемые расширения TakenOverBy сохраняют историю услуги и не переносят доверие на другого поставщика.

Допустимость алгоритмов определяется пороговыми значениями закреплённой версии DSS 6.5.1; математическая целостность указывается отдельно.

В Windows дополнительный компонент trustlists включает TLS с проверкой через хранилище сертификатов операционной системы.

Снимок доверенных списков имеет частичный охват. При отсутствии доказательств результат остаётся неопределённым. Выбранные сравнительные тесты DSS не доказывают полной эквивалентности eIDAS или PAdES.
