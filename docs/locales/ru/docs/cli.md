<a id="cli-reference"></a>
# Справочник CLI

Используйте `onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"CONFIDENTIAL","opacity":0.25}'` для добавления текстового водяного знака PDF. Смотрите [руководство по водяным знакам](watermark.md) для позиционирования, поворота, диапазонов страниц и повторяющихся макетов.

Необратимое скрытие доступно через `onekit run pdf-redact` и `onekit run image-redact`; выбранные области задаются в `regions`. В [руководстве по скрытию данных](redaction.md) описаны координаты, растеризация и гарантии конфиденциальности экспортируемых файлов.

Используйте `onekit run dev-regex-test input.txt -o regex-results.json --options '{"pattern":"[0-9]+","flags":"g"}'` для тестирования регулярных выражений JavaScript. Требуется Node.js; см. [руководство по тестированию регулярных выражений](regex.md) для захватов, замен и ограничений выполнения.

Стандартные штрихкоды доступны через `onekit run text-to-barcode`, `onekit run scan-barcode` и `onekit run barcode-to-text`. Установите дополнительные `barcode` или `qrcode`. Смотрите [настройки штрихкодов и поддерживаемые стандарты](qrcode.md#standard-linear-barcodes).

`onekit --version` сообщает версию ядра. `python -m onekit` вызывает тот же CLI.

| Команда | Поведение |
| --- | --- |
| `onekit list [--group GROUP] [--json]` | Изучите инструменты, контракты, доступность и лояльность. |
| `onekit doctor [TOOL_ID] [--json]` | Проверьте пакеты, движки и блоки лицензий Python. |
| `onekit run TOOL_ID INPUTS -o OUTPUT` | Обрабатывает файлы; шифрование также поддерживает каталоги. |
| `onekit pipeline --steps WORKFLOW INPUTS -o OUTPUT` | Выполняет от 1 до 16 последовательных шагов инструментов из файла JSON. |
| `onekit engines install [--directory DIRECTORY]` | Установите заблокированные движки разработчика Node; требуется Node/npm. |
| `onekit download URL -o OUTPUT [--quality best\|720\|1080] [--force]` | Скачайте одно видео через yt-dlp; требуется интернет и FFmpeg. |

`run` принимает `--options` с объектом JSON, `--ask-password` и `--force`. Конвейеры также поддерживают запрос пароля и флаг перезаписи. Используйте имя файла для одного результата или директорию для нескольких выходов. Места без расширения считаются директориями. Конфликтующие имена выходных файлов отклоняются.

<a id="local-agents-and-automation"></a>
## Local agents and automation

**Ваш CLI. Ваш CLI для агентов.** OneKit полезен как на вашем терминале, так и как набор инструментов для обработки файлов для локальных агентов AI, которые могут выполнять команды shell или запускать подпроцессы. Агент может находить контракты инструментов, проверять требования, запускать выбранную операцию и просматривать её выходные файлы.

```sh
onekit list --json
onekit doctor pdf-merge --json
onekit run pdf-merge first.pdf second.pdf -o combined.pdf
onekit pipeline --steps workflow.1kit input.pdf -o output/
```

`list --json` показывает идентификаторы инструментов, принимаемые входные данные, форматы вывода, опции, ограничения и примечания по точности. `doctor TOOL_ID --json` сообщает о готовности, отсутствующих зависимостях и блокировках по лицензионной политике. Разбирайте эти JSON ответы, а не удобочитаемые списки. `run` и `pipeline` записывают свои результаты в указанное с помощью `-o` место назначения; у них нет общего флага `--json` для ответа. Некоторые инструменты создают JSON отчётные файлы.

Для локального агента сначала обнаружьте инструмент, проверьте его требования, затем вызовите его с явными путями и объектом JSON в `--options`, где это необходимо. Передавайте аргументы subprocess в виде списка, чтобы сохранять пути и JSON без оболочечных кавычек. Проверьте статус выхода перед использованием результатов:

| Код завершения | Значение |
| --- | --- |
| `0` | Команда выполнена успешно. |
| `1` | `doctor` обнаружил отсутствующие требования или блок политики; проверьте отчет. |
| `2` | Недопустимые аргументы или ошибка обработки/ввода/вывода; смотрите stderr. |
| `130` | Команда отменена прерыванием с клавиатуры. |

Выбирайте новый путь для каждого задания; существующие файлы не изменяются, если не указан `--force`. `--ask-password` требует интерактивной консоли. Подготовьте зависимости и кэши моделей перед автономным запуском: отсутствие компонентов может вызвать автоматическую установку и загрузку из сети, а некоторые нативные установщики требуют взаимодействия или повышенных прав. Сетевые инструменты также обращаются к указанным источникам.

Обработка файлов происходит на вашем устройстве. Если агент использует удалённую модель, то то, как агент обрабатывает содержимое файлов и результаты команд, определяет, что отправляется этому провайдеру. Та же лицензия [PolyForm Shield](licenses.md) применяется для использования агентом.

<a id="tool-options"></a>
## Tool options

Генерация QR, конфигурация vCard/Wi-Fi, сканирование изображений и обратное декодирование документированы в [руководстве по QR-кодам](qrcode.md). Установите дополнение `qrcode`, затем используйте `onekit run text-to-qrcode input.txt -o code.png` или `onekit run scan-qrcode photo.jpg -o decoded.json`.

Нумерация страниц начинается с 1. `pages` принимает номера и возрастающие диапазоны, например `1,3-5`. При упорядочивании и извлечении сохраняются порядок и намеренные повторы. Поворот задаётся значением, кратным 90, и по умолчанию применяется ко всем страницам. Редактирование PDF добавляет `text` на `page` в координатах `x`/`y`, заданных в пунктах PDF от левого нижнего угла; существующее содержимое не перераспределяется. Для подписания нужны путь к PKCS#12-`certificate` и его `password`.

Формат изображения `format` поддерживает PNG, JPEG, WebP, TIFF, BMP, ICO, GIF и PDF, если применимо. `quality` равен 1–100. `box` выражается в пикселях как `[left, top, right, bottom]`. Анимация/метаданные могут быть удалены; прозрачность преобразуется в белый для JPEG/PDF. Сжатие может увеличивать уже оптимизированный файл.

Параметр `sheet` выбирает лист; по умолчанию используется активный лист. Excel при чтении использует кэшированные значения формул. JSON–Excel ожидает массив объектов. CSV `delimiter` по умолчанию использует запятую. Строки, похожие на формулы, XLSX остаются текстом; импортируйте недоверенные CSV как текст в приложениях для работы с таблицами.

Конвертация кодирования принимает `source_encoding` и `encoding`. Другие текстовые инструменты используют UTF-8.. Для PDF, JPEG и PNG, `metadata` принимает описательные текстовые поля `Title`, `Author`, `Subject`, `Keywords` и `Comment`. Неуказанные поля сохраняются; пустая строка очищает значение поля. Помощник Python `onekit.tools.file_metadata.read_metadata(artifact)` считывает эти поля без изменения артефакта, включая поддерживаемые EXIF, PNG текст и XMP значения. Другие форматы метаданных используют необязательные пары тег/значение ExifTool в рамках своего формата. Подписи инспектора не идентифицируют все проприетарные типы файлов.

Сравнение ноутбука `mode` это `both`, `markdown` или `code`. Режим LaTeX это `all` или эвристический `text`. Сравнение PDF/Word извлекает текст. Diff JSON содержит нормализованные стороны, изменённые блоки и единый патч, включая различия в завершающих переносах строк. OCR `language` использует установленные коды Tesseract и `dpi` это 36–300. Конвертация PDF/A требует лицензированного `icc_profile`; проверяйте архивный вывод отдельно.

Варианты медиа включают `format`, `codec` и `bitrate`, в зависимости от FFmpeg сборки. Шрифты поддерживают `ttf`, `otf`, `woff` и `woff2`, сохраняя технологию контуров. Архивы поддерживают комбинации ZIP и TAR/gzip/bzip2/xz.

<a id="limits-and-errors"></a>
## Limits and errors

Смотрите [проверку ввода](input-validation.md) для типов, ограничений по байтам/количеству, проверки подписи/контейнера и правил распаковки архивов, применяемых к каждой используемой утилите. Это касается прямых Python API вызовов и каждого шага конвейера, а также CLI. Запустите `onekit list --json` для точных машинно-читаемых контрактов.

Входные данные ядра: 256 файлов и 128 MiB. Конвейеры: 16 шагов. Изображения и отрисованные страницы: 40 миллионов пикселей. Сравнение: 10 000 строк и 2 миллиона символов. Распаковка архивов: 128 MiB, 4096 элементов и проверка коэффициента расширения. Для внешних движков действуют ограничения времени. Большие корректные входные данные могут превышать эти намеренно установленные пределы.

Коды завершения: 0 успех; 1 неполный диагностический отчёт doctor; 2 ошибка ввода/обработки; 130 отмена. Валидаторы могут успешно выдавать `valid: false`: проверяйте отчет, а не предполагайте, что код выхода 0 означает действительный источник. Проверка типа/импорта может требовать полного проекта. Проверка синтаксиса Python никогда не выполняет ввод.

Английский язык по умолчанию. Будущие переводы CLI используют gettext-домен `onekit` в `onekit/locales`; ID, имена команд и ключи JSON остаются независимыми от языка.

Слияние блокнотов принимает `merge` с `from` (`left` или `right`) и отсчитываемый с нуля индекс изменённой ячейки `block` вместе с `mode`. Оно создает обновленный целевой блокнот и сохраняет исключенные ячейки и метаданные блокнота. Унифицированные патчи описывают сравниваемое представление и обычно не являются патчами для необработанных PDF, Word или контейнеров блокнотов.

<a id="image-effects"></a>
## Image effects

`onekit run image-effects photo.jpg --options '{"effect":"pixelate","strength":16}' -o output` сочетает размытие, пикселизацию, коробчатое размытие, сплошное покрытие и градации серого в одном инструменте. Используйте `scope: "selected"` с прямоугольниками с нормализованными координатами в `regions`, чтобы выбрать конкретные области. Смотрите [руководство по эффектам изображения](image-effects.md) для всех опций и ограничений.

<a id="portable-workflows"></a>
## Portable workflows

`onekit workflow export SOURCE -o workflow.1kit` проверяет массив шагов прежнего формата или документ рабочего процесса и сохраняет переносимый документ. `onekit workflow import workflow.1kit -o saved.1kit` проверяет и сохраняет импортированный документ. Обе команды исключают пароли и отказываются перезаписывать существующие выходные пути, если не указан `--force`. Ни одна из команд не обрабатывает файлы.

Запустите импортированный рабочий процесс с `onekit pipeline --steps saved.1kit INPUTS -o OUTPUT`. Расширение .1kit определяет документы OneKit; устаревшие файлы рабочей среды .json и .onekit.json и массивы шагов остаются поддерживаемыми. Документы рабочих процессов — это UTF-8 JSON, максимум 1 MiB, со следующей структурой:

```json
{
  "format": "onekit-workflow",
  "version": 1,
  "steps": [{"tool": "dev-format-json", "options": {}}]
}
```

<a id="automatic-setup"></a>
## Automatic setup

`onekit run`, `onekit download` и `onekit pipeline` устанавливают недостающие пакеты Python и нативные движки перед обработкой. Зависимости хранятся в пользовательском кэше OneKit, без изменения системной установки Python. Модели Whisper и U2Net загружаются автоматически при первом использовании и кешируются для последующих запусков. Данные языков OCR загружаются для запрошенных языков.

Первый запуск требует подключения к интернету и достаточного места на диске. Нативные движки используют conda-forge через приватную установку micromamba или системный менеджер пакетов для движков, недоступных там; доступность зависит от операционной системы и архитектуры. Ошибки настройки останавливают обработку и могут быть повторены. `onekit doctor` проверяет готовность без установки чего-либо. `ONEKIT_CACHE` меняет место хранения кэша настройки. `ONEKIT_ALLOW_COPYLEFT=0` продолжает блокировать ограниченные движки.

<a id="local-license-and-copyright-estimates"></a>
## Local license and copyright estimates

Группа `licenses` предоставляет `license-pdf`, `license-word`, `license-powerpoint`, `license-excel`, `license-video`, `license-audio`, `license-image`, `license-font`, `license-epub`, `license-code` и `license-dataset`.

```sh
onekit run license-image photo.jpg -o report.json
onekit run license-pdf --url https://example.org/document.pdf -o report.json
onekit run license-code project.zip -o report.json
onekit run license-code ./project -o report.json
onekit run license-code --url https://github.com/owner/repository --options '{"ref":"main"}' -o report.json
onekit run license-code --url https://gitlab.com/group/project -o report.json
onekit run license-dataset data.csv LICENSE metadata.json -o report.json
```

**Каждый результат — это непроверенная оценка, требующая ручной проверки.** В нём указаны заявленные метаданные, уведомления об авторских правах, имена создателей, синтаксис SPDX и предполагаемые совпадения текста лицензии с их местоположением. Это никогда не подтверждает право собственности и не даёт разрешения на использование работы. Отсутствие заявлений не означает, что работа находится в общественном достоянии или доступна для свободного использования. Имена создателей не доказывают авторские права. Ознакомьтесь с оригинальным источником, полными условиями и предполагаемым использованием; зависимости проекта и ресурсы могут иметь отдельные лицензии. Официальные ссылки объясняют стандарты, а не подлинность или применимость заявлений в загруженной работе.

<a id="downloads-image-transforms-and-url-inspection"></a>
## Downloads, image transforms and URL inspection

```sh
onekit run audio-download --url 'https://example.org/audio.flac' -o downloads/
onekit run audio-download --url 'https://example.org/audio.wav' --options '{"format":"mp3","quality":"320"}' -o downloads/
onekit run image-download --url 'https://example.org/photo.jpg' -o downloads/
onekit run image-rotate-flip photo.png --options '{"angle":"90","flip":"horizontal"}' -o rotated.png
onekit run url-inspect --url 'https://example.org/path?x=1#section' -o report.json
```

Скачивание изображения или аудиофайла не даёт права на распространение или повторное использование.

Вращение изображения сначала применяет ориентацию EXIF, затем поворачивает по часовой стрелке на 0/90/180/270 градусов, а затем выполняет отражение по горизонтали, вертикали или обоим направлениям в повернутой системе координат. Экспортирует PNG, сохраняя декодированные пиксели RGBA и прозрачность без метаданных; анимированные и многостраничные изображения отклоняются. Лимит — 40 миллионов пикселей.

<a id="remove-text-formatting"></a>
### Remove text formatting

`onekit run text-strip-formatting document.docx -o plain.txt` экспортирует основной текст Word как UTF-8 TXT. Также поддерживаются файлы TXT, HTML и Markdown, до 8 MiB. Используйте `--options '{"input_format":"html"}'` для интерпретации HTML, сохранённого в файле TXT. Распознавание OCR не выполняется.
