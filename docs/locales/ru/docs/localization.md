# Локализация CLI

Языки: `en`, `it`, `fr`, `es`, `de`, `ru`, `zh` (упрощённый китайский). Выберите один с `onekit --language it ...` или `ONEKIT_LANGUAGE=it`. Локаль операционной системы используется, если ни одна не задана. Не поддерживаемые локали используют английский. Названия команд, ключи параметров, пути, идентификаторы формата и машиночитаемые контракты JSON остаются неизменными. Человекопонятная помощь, статусы, предупреждения и известные ошибки локализованы. Диагностика внешнего движка сохраняет исходный текст.

Каждый человек или ИИ, добавляющий или изменяющий инструмент, ОБЯЗАН обновить все семь каталогов текстов в том же изменении. Имена, справка, описания, сообщения об ошибках, уведомления, README и документация инструментов должны сохранять соответствие один к одному. Не подставляйте английский текст вместо отсутствующих переводов. Сохраняйте заполнители, примеры кода, URL и юридические уведомления, которые требуется воспроизводить дословно. Проверяйте смысл и терминологию в контексте.

Каталоги: `src/onekit/locales/{language}.json`. Код представления: `i18n.py`. Сообщения на английском — это нормализованные ключи; алгоритмы обработки остаются независимыми. Независимый реестр языков — `src/onekit/locales/languages.json`, включая псевдонимы операционной системы. Добавьте запись в реестр и полный каталог вместе. Проверенная терминология записывается в `scripts/localization-reviewed.json`; применяйте её с `python scripts/apply_localization_review.py src/onekit/locales` перед аудитом.

1. Редактируйте английское сообщение или документацию в исходном файле.
2. Выполните `python scripts/localization_inventory.py`.
3. Обновите все остальные языковые каталоги и удалите устаревшие записи. Скрипты подготовки могут создавать черновики переводов; созданные тексты необходимо проверить.
4. Запустите `python scripts/audit_localization.py` и `pytest tests/test_i18n.py`.
5. Выполните `python scripts/localize_docs.py`, чтобы заново создать переведённые документы Markdown в `docs/locales/{language}/`, сохранив относительную структуру исходных документов.

Команда оффлайн-авторинга принимает локальный каталог модели Argos, за которым следуют каталоги. CTranslate2 и SentencePiece являются зависимостями авторинга, а не требованиями времени выполнения CLI. Сервис перевода CLI не используется.

Переводы и документация CLI поддерживаются независимо от любого сайта, который встраивает библиотеку обработки. Здесь принадлежат только публичные ссылки для использования.
