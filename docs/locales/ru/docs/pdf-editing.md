# Редактирование текста PDF

Проверьте исходный файл, чтобы получить стабильные ID текстовых блоков и оригинальный текст:

```python
from onekit.api import execute
from onekit.models import Artifact

source = Artifact("document.pdf", open("document.pdf", "rb").read())
inspection = execute("pdf-edit", [source], {"mode": "inspect"})
box = inspection.details["pages"][0]["runs"][0]
result = execute("pdf-edit", [source], {
    "edits": [{"page": 1, "id": box["id"], "original": box["text"], "text": "Updated text"}]
})
open("edited.pdf", "wb").write(result.files[0].data)
```

CLI принимает тот же объект опций через `--options`. `edits` может быть массивом JSON или строкой, содержащей этот массив. Режим инспекции выводит `*.text-boxes.json`; режим редактирования выводит `*.edited.pdf`. Оригинальный PDF сохраняется без изменений между инспекцией и редактированием. Устаревшие идентификаторы, повторяющиеся изменения и несоответствие оригинального текста отклоняются.

Для сканов сначала требуется OCR. Прямое редактирование не предлагается для текста в повторно используемых объектах Form XObject, текстовых операторов с одинарной или двойной кавычкой, вертикального письма и текста, используемого как маска обрезки. Шрифты с неполными таблицами соответствий также могут быть недоступны. Вставляемый символ должен присутствовать в таблице соответствий исходного шрифта; движок сообщает о неподдерживаемых символах, а не меняет шрифт без предупреждения. Редактирование выполняется в пределах одной строки и не меняет разбиение абзацев на строки. Для удаления конфиденциальной информации используйте специальный инструмент необратимого скрытия, включая удаление копий в аннотациях, истории документа, метаданных и других объектах PDF.

Предыдущие варианты `text`, `x`, `y`, `page` остаются доступными для скриптов, которые добавляют текстовые наложения. Используйте `edits`, чтобы заменить существующий текст.
