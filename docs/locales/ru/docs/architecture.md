# Руководство по архитектуре и расширениям

`Artifact(name, data)` — это неизменяемый именованный байтовый блок. `Result(files, warnings, details)` содержит выводы и уведомления о точности. `execute(tool_id, files, options)` проверяет контракты и лениво импортирует адаптер обработки. `pipeline(steps, files)` объединяет операции и применяет шаги с одним входным файлом к каждому предыдущему результату.

Каталог определяет стабильные идентификаторы, семейства, допустимые и выходные типы, кратность, опции, точность, ограничения и зависимости. Адаптеры обработки независимы от доступа к файловой системе CLI. Портабельные имена не поддерживают обход и зарезервированные имена устройств. Вывод CLI по умолчанию сохраняет существующие файлы. Вызовы родного движка используют массивы аргументов, временные директории и ограниченные тайм-ауты.

Чтобы добавить инструмент, реализуйте его адаптер семейства, объявите запись в каталоге, добавьте регрессионные тесты для семантики и некорректного ввода, объявите необязательные зависимости и проверьте лицензии. Перегенерируйте каталоги инструментов с `python scripts/tool_docs.py`. Задокументируйте точность и требования к платформе.


API обработки версии 1 описан в `contracts/processing-v1.json`. Перед отправкой изменений выполните `python scripts/check_contracts.py`. Добавление инструментов, форматов и параметров сохраняет совместимость; удаление существующих идентификаторов или параметров, изменение типов выходных данных или сужение контрактов входных данных требует явно определённой миграции с указанием версии. Внутренние алгоритмы и организация обработчиков могут меняться без изменения публичного контракта.

`ExecutionContext` позволяет вызывателям Python уменьшать бюджет по партии и на каждый инструмент, а также предоставлять надежный локальный считыватель метаданных медиа. Он не принимает сервисы движка через пользовательские опции инструментов. Контексты неизменяемы, ограничены одной сессией и совместно используются шагами конвейера. CLI использует стандартные локальные сервисы движка.

Адаптер источника Node делегирует правила форматирования и минификации `tools/developer/source_engine.mjs`. Его загрузчик движка является зависимостью на уровне процесса; исходный текст не может выбирать произвольные пакеты или исполняемые команды.
