# OneKit 0.5.0

Первоначальный выпуск офлайн-CLI и API обработки на Python с 230 инструментами для документов, PDF, изображений, медиа, архивов, шрифтов, утилит для разработчиков, QR-кодов, заявлений о лицензиях и проверки файлов. Базовая установка не имеет зависимостей времени выполнения; дополнительные пакеты и внешние движки обеспечивают работу выбранных инструментов.

Включает проверку ограниченного ввода, повторно используемые рабочие процессы, настройку локальных зависимостей, контракты обработки для конкретных форматов и инспекцию лицензий на основе источников. Отчёты по лицензиям остаются неподтверждёнными оценками, требующими ручной проверки.

Обновления производительности ускоряют подготовку непрозрачного изображения и проверку текста. Неиспользуемые импорты и избыточные назначения движка разработчика были удалены.

Модельные движки необязательны: при необходимости установите `background` или `transcription` дополнительный пакет. U2Net запускается напрямую с ONNX Runtime и кэшированной моделью с проверкой контрольной суммы. Whisper использует faster-whisper. Файлы остаются локальными; при первом запуске загружаются веса модели. Для обработки видео требуется FFmpeg и ffprobe. Для скачивания видео используется отдельный дополнительный пакет `video`.

Обновляет Pillow до версии 13 и закреплённую версию certifi для устранения проблем, указанных в опубликованных бюллетенях безопасности. Переносимая группа дополнительных зависимостей `all` по-прежнему отделена от движков моделей и функций подписания.
