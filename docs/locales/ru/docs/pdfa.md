# PDF/A конвертация и проверка

CLI и Python API вызывают `onekit.tools.pdfa`. Этот модуль не запускает никаких исполняемых файлов и не открывает сетевых подключений. Конвертация использует pdftopdfa 0.9.24 для шрифтов, цвета и нормализации, затем pikepdf 10.17.0 PDF/A для подготовки и проверки точных окончательных байтов. Нет зависимости Ghostscript.

Конверсия поддерживает PDF/A-2b (по умолчанию) и 3b. Валидация поддерживает 1b, 2b и 3b. Соответствие A/U, PDF/A-4 и OCR выходит за рамки этого адаптера. Несовместимые конструкции отмечаются как `not_checked`, а не как соответствующие требованиям. `pass` из этого консервативного белого списка не является архивной сертификацией; независимая veraPDF валидация по-прежнему рекомендуется для институциональных представлений.

```
onekit run pdf-to-pdfa input.pdf --options '{"profile":"2b"}' -o output
onekit run pdf-validate-pdfa output/input.pdf -o report
onekit doctor pdf-to-pdfa --json
```

CLI автоматически устанавливает закреплённый, проверенный **не-OCR уровень-B поднабор** upstream-пакетов. Он специально не устанавливает PaddleOCR, OCRmyPDF или криптографический бэкенд для неиспользуемого парсера PDF в pdfminer: никаких опций не передаётся в upstream OCR или A/U tagging API. Upstream `pdftopdfa` wheel остаётся без изменений. Его метаданные пакета включают более широкий набор требований для API, которые OneKit не использует. Опциональный `[pdfa]` extra устанавливает проверенные зависимости. Для прямого использования Python API установите этот extra, а затем `pip install --no-deps pdfminer.six==20260107 pdftopdfa==0.9.24`. Не устанавливайте дополнительные OCR-пакеты upstream для этого адаптера. Обязательные требования OCR от Upstream в данный момент фиксируют старую версию PyYAML, несовместимую с OneKit. Конвертация требует Python 3.12+; автономная проверка работает на Python 3.11+. Запустите `python scripts/check_licenses.py --include-pdfa` для проверки выбранной среды выполнения.

Ранее используемый вариант `icc_profile` остаётся допустимым как необязательный локальный файл ICC; по умолчанию сохраняются встроенные лицензированные профили конвертера RGB/CMYK. Зашифрованные PDF и цифровые подписи отклоняются при конвертации. Конвертация может заменять шрифты и удалять действия или метаданные, не предназначенные для архивации; успешный результат сопровождается предупреждениями. Неудачные или неполностью проверенные кандидаты никогда не возвращаются как преобразованные файлы PDF/A. Исходные файлы не перезаписываются. Отчёт проверки JSON сохраняет поля `compliant` и `reports` и добавляет проверенный профиль, вердикт и движок.
