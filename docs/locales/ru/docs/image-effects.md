# Эффекты изображения

```sh
onekit run image-effects photo.jpg --options '{"effect":"pixelate","strength":16}' -o output
onekit run image-effects photo.jpg --options '{"effect":"blur","strength":12,"scope":"selected","regions":[{"x":0.1,"y":0.2,"width":0.3,"height":0.25}]}' -o output
```

`strength` — целое число от 1 до 100 пикселей (не менее 2 для пикселизации). `scope` принимает значение `all` (по умолчанию) или `selected`; режим выбранных областей требует от 1 до 500 прямоугольников с нормализованными координатами от 0 до 1 и необязательным `page: 1`. Для сплошной заливки `color` задаётся в формате `#RRGGBB`. Интенсивность не влияет на оттенки серого и сплошную заливку. Перекрывающиеся области обрабатываются по исходным пикселям, без накопления размытия. Обрабатывается не более 80 миллионов выбранных пикселей с учётом перекрытий.

Размытие и пикселизация — визуальные эффекты, которые не гарантируют удаления конфиденциальных деталей. Используйте необратимое скрытие данных на изображении, если содержимое должно быть закрыто без возможности восстановления.
