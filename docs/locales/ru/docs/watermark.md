# Водяной знак PDF

В категории PDF загрузите PDF, введите текст и настройте непрозрачность, цвет, шрифт, поворот и позицию. Предпросмотр показывает положение водяного знака на выбранной странице. Экспортируйте, чтобы проверить окончательное отображение шрифта PDF. Выберите один водяной знак или повторяющуюся сетку 3 × 4. Текст автоматически уменьшается при необходимости, чтобы поместиться на страницу или в ячейку, до предела читаемости в шесть пунктов. Зашифрованные PDF-файлы сначала нужно разблокировать. После изменения документа существующие цифровые подписи больше не проходят проверку действительности; инструмент предупреждает, если есть поля подписи.

```sh
onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"CONFIDENTIAL","pages":"1,3-5","opacity":0.25,"angle":45}'
onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"DRAFT","layout":"repeat","color":"#b00000"}'
```

| Опция | Значения / по умолчанию |
| --- | --- |
| `text` | 1–200 символов, до пяти строк; по умолчанию DRAFT |
| `pages` | Диапазоны с единицей, например `1,3-5`; пустое или пропущенное означает все |
| `font` | Helvetica-Жирный (по умолчанию), Helvetica, Times-Roman, Courier |
| `font_size` | 8–160 точки; по умолчанию 48, автоматически подбирается при необходимости |
| `color` | Шестизначный шестнадцатеричный код; по умолчанию #666666 |
| `opacity` | 0.05–1; по умолчанию 0.25 |
| `angle` | - 180–180 градусы, против часовой стрелки; по умолчанию 45 |
| `position` | центр, верхний левый/центр/правый, средний левый/правый, нижний левый/центр/правый |
| `layout` | одиночный (по умолчанию) или повтор (3 × 4 сетка; положение игнорируется) |
| `margin` | 0–144 очков; по умолчанию 24 |

Шрифты поддерживают западноевропейские символы и знаки препинания, включая итальянские буквы с диакритическими знаками. Неподдерживаемые символы вызывают явную ошибку. Можно обработать до 512 страниц. Положение определяется с учётом видимой ориентации области обрезки; исходный поворот и координаты аннотаций сохраняются. Водяной знак помечает видимое содержимое, но не удаляет расположенное под ним содержимое.
