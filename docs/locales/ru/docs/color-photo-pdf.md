# Цвет, восстановление фото и формы PDF

Эти инструменты доступны через стандартную команду `onekit run TOOL ... --options JSON` и Python `execute` API. Смотрите `onekit run --help` для аргументов ввода/вывода. Все координаты ниже относятся к изображению после ориентации EXIF или к отображаемой странице PDF после поворота.

- `color-picker`: просмотрите файл UTF-8, содержащий `#RRGGBB`, или возьмите образец изображения с целочисленными координатами пикселя `x` и `y` (по умолчанию в центре). Выводит HEX, RGB, OKLCH, контраст черного/белого текста и оригинальный RGBA для изображений. Видимые цвета накладываются на белый фон.
- `image-extract-colors`: `colors` (2–32, по умолчанию 6). Квантование методом медианного сечения для миниатюры размером до 256 × 256. Полностью прозрачные пиксели исключаются; частичная прозрачность накладывается на белый фон. Доли описывают этот образец.
- `jpg-to-svg`: `colors` (2–32, по умолчанию 16), `resolution` (32–512, по умолчанию 256). Квантует ограниченное изображение, объединяет горизонтальные участки одного цвета по вертикали и записывает заполненные пути SVG. Встраивание растрового изображения не выполняется. Это создаёт векторные плитки с постеризованным видом, а не плавное трассирование кривых.
- `image-repair`: без `regions` применяет медианный фильтр `size` 3 или 5 к изолированным пятнам. С регионами восстанавливает выбранные пиксели с помощью фиксированных окружающих пикселей и дискретной гармонической диффузии (`iterations` 10–500, по умолчанию 200).
- `image-remove-watermark`: требует `regions`; использует ту же локальную реконструкцию. Оценивает пропавшие пиксели и не может восстановить скрытое оригинальное содержимое. Текстуры, крупные отметки и сложные фоны могут давать плохие результаты.
- `image-sharpen`: `method` — `unsharp` (по умолчанию) или `deconvolution`. `radius` от 0.3 до 5 задаёт радиус нерезкого маскирования или оценку гауссова рассеяния точки. Для нерезкого маскирования `amount` составляет от 0 до 300 процентов (по умолчанию 150). Метод Ричардсона–Люси использует от 1 до 30 `iterations` (по умолчанию 10), зеркальное продолжение границ и FFT-свёртку для не более чем одного миллиона исходных пикселей. Предполагается гауссово размытие; произвольные движения не исправляются. Оба метода могут усилить шум и ореолы.
- `pdf-remove-watermark`: по умолчанию `mode: "remove"` удаляет группы `/Artifact`, помеченные `/Subtype /Watermark` (включая именованные ресурсы свойств) и аннотации `/Watermark`. Опционально `text` сопоставляет объекты полного текста с нормализованными пробелами, декодируя глифы через их шрифтовое кодирование/карту ToUnicode. Вложенные объекты Form XObjects обрабатываются рекурсивно. Используйте `mode: "inspect"`, чтобы получить отчет JSON по тексту, изображениям и вызовам Form XObject; передавайте выбранные идентификаторы как `objects` в режиме удаления. Выбор Form XObject удаляет всю связанную с ней графическую группу. Изменённые Form XObject копируются для каждого вызова, так что невыбранные использования общего ресурса остаются без изменений. Идентификаторы относятся к одному и тому же оригинальному PDF и должны быть проверены снова после изменений. Это удаление объектов рисования, а не безопасное необратимое скрытие данных: неиспользуемые объекты ресурсов могут остаться в результате. Оно не определяет произвольное неотмеченное содержимое как водяной знак автоматически, и водяной знак, встроенный в отсканированное изображение, не может быть отделён от этого изображения. Отчёт содержит до 2000 кандидатов, рекурсия ограничена 12 уровнями, а обработка — 300 000 графических операций. При нулевых совпадениях выдаётся явная ошибка.
- `pdf-make-fillable`: `fields` — массив JSON стандартных элементов AcroForm. У каждого элемента есть уникальное ASCII-имя `name`, тип `type` (`text`, `checkbox`, `choice`), номер страницы `page` начиная с 1 и нормализованные координаты `x`, `y`, `width`, `height`. Поддерживаются необязательный параметр `required`, `multiline` для текста и `choices` для вариантов выбора. Существующие поля и содержимое страниц сохраняются. Повторяющиеся имена, зашифрованные PDF и XFA отклоняются. Автоматического обнаружения пустых областей нет.

Области изображения — это массивы объектов, таких как `{"page":1,"x":0.2,"y":0.3,"width":0.1,"height":0.05}`. Координаты нормализуются к 0–1 от верхнего левого угла. Восстановление поддерживает до 100 прямоугольников, не более 35% изображения и ограничивающий прямоугольник (включая отступ) размером в миллион пикселей. Изменяются только RGB внутри маски; оригинальный альфа-канал сохраняется. Результаты — это PNG без исходных метаданных. Анимированные/многокадровые изображения отклоняются. Общая декодировка изображений ограничена 40 миллионами пикселей. PDF ограничены 256 страницами, а формы — 200 новыми полями.

Пример использования Python:

```python
from onekit import Artifact, execute

result = execute("pdf-make-fillable", [Artifact("source.pdf", pdf_bytes)], {
    "fields": [{"name": "Name", "type": "text", "page": 1,
                "x": 0.1, "y": 0.2, "width": 0.4, "height": 0.05}]
})
```

Просмотрите полученные файлы и сохраните оригиналы. Для заполнения и сохранения форм требуется совместимый ридер PDF.
