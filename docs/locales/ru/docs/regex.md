# Тестер регулярных выражений

```sh
onekit run dev-regex-test input.txt -o regex-results.json --options '{"pattern":"(?<word>\\w+)","flags":"g","enable_replacement":true,"replacement":"[$<word>]"}'
onekit doctor dev-regex-test
```

Отчет JSON включает шаблон, флаги, количество совпадений, статус усечения, точно совпавший текст, позиции начала/конца, пронумерованные группы захвата и именованные группы. Несовпавшие группы равны null. Позиции используют кодовые единицы UTF-16, как делает JavaScript, поэтому астральные символы Unicode занимают две единицы. Пустые глобальные совпадения продвигаются корректно, включая при флаге Unicode.

Установите `enable_replacement` в true и задайте `replacement` для предварительного просмотра подстановок. Поддерживаемые токены соответствуют подстановкам в строках JavaScript: `$$`, `$&`, `$1`–`$99`, `$<name>`, `$'` и префиксный токен из знака доллара и обратной кавычки. Подстановки никогда не изменяют тестовые входные данные. Если список совпадений усечён, результат подстановки не показывается, чтобы не представлять неполный результат.
