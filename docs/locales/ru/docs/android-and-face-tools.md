# Пакеты Android и автоматическое размытие лиц

Упаковывает один автономный APK и его метаданные в архив XAPK, не изменяя байты APK. Раздельные APK отклоняются. Требуется установщик с поддержкой XAPK; подписи не проверяются.

Извлекает исходные APK и данные OBB, не изменяя байты APK. Раздельные APK нужно устанавливать вместе; они не объединяются в универсальный APK. Подписи не проверяются.

Обнаруживает лица локально с помощью YuNet и размывает их в новом PNG. Перед публикацией проверьте каждое лицо: автоматическое обнаружение может пропускать лица, а размытие не гарантирует анонимность. Только однокадровые изображения размером до 16 миллионов пикселей.

Выходной PNG не содержит исходных метаданных. Если лица не обнаружены, изображение не экспортируется.

```sh
onekit run apk-to-xapk app.apk -o app.xapk
onekit run xapk-to-apk app.xapk -o extracted/
onekit run image-blur-faces photo.jpg -o blurred.png
```

Установите необязательный набор зависимостей `faces` для локального обнаружения лиц.
