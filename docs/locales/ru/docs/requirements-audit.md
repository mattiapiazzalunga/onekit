# Проверка требований CLI

`tests/test_requirements.py` проверяет покрытие каталога, CLI вызовы и некорректные конвейеры. `tests/test_core.py` проверяет контракты обработки и семантику вывода. Валидация входных данных, распаковка архивов, шифрование и защита файловой системы имеют отдельные регрессионные тесты.

Запустите `python -m pytest -q` для стандартного набора. Отдельно установленные движки тестируются с `python -m pytest -q -m native`; перед выполнением этих проверок подготовьте зависимости, описанные в `docs/engines.md`. Успешное выполнение стандартного набора не проверяет все внешние движки и все поддерживаемые платформы.
