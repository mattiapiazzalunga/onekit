# 行为准则

欢迎所有贡献者，无论背景、身份、经验或能力。保持尊重，把批评集中在工作本身。提供建设性、可执行的反馈。

在项目空间中，骚扰、威胁、歧视、暴露个人信息、泄露私人信息、性化关注和持续干扰都是不可接受的。如有问题，请私下向 `hello@mattiapiazzalunga.com` 报告。

维护者会谨慎处理报告，并适度采取澄清、警告、内容删除、临时限制或排除措施。报复行为不可接受。维护者遵循相同标准，并在处理报告时披露冲突。
