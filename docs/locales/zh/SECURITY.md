# 安全策略

向 `security@onekit.org` 私下报告漏洞时，请提供版本、平台、工具、依赖版本、影响和合成复现步骤。不要在公共追踪器上发布敏感文件、凭证或可被利用的私人报告。修复针对最新稳定版本；不保证响应时间。

核心对路径、输入大小、归档解压、图像像素数、差异对比和处理流水线施加限制。加密采用带身份验证的 AES-256-GCM，每次生成新的盐值和 nonce，并使用 scrypt；丢失的密码无法恢复。默认保留已有输出文件。Python 验证仅解析源代码，不执行代码。

外部转换器/编译器是独立的本地程序，而不是完整的沙箱。请保持它们更新，并使用操作系统控制来隔离有害的文档。CLI 不是未经身份验证的远程转换服务。编辑已签名的 PDF 可能会使签名失效；PDF 的权限不等同于加密完整性。

普通检查绝不能接触发布秘密。稳定标签用于标识已审核的受保护主提交。依赖、许可证和安全性失败会阻止发布。没有测试套件能保证对所有损坏的输入或攻击免疫。
