# 贡献

帮助建设 OneKit 的开放革命：为每个人提供日常工具，从动手任务到由本地 AI 代理运行的工作流程。贡献力量，让工具更高效、更有效：提升速度和内存使用，修复错误结果，增加回归示例，或者澄清文档和代理工作流程。

在 [GitHub 问题](https://github.com/mattiapiazzalunga/onekit/issues) 和 [网站需求看板](https://onekit.org/requests/) 上查找工作。实施前讨论接口约定变更和重大依赖。

保持 Artifact/Result 独立于 CLI/HTTP/存储。优先考虑小型可选依赖和延迟导入。绝不单纯为了验证而执行用户代码。使用参数数组，不执行 shell 命令，并使用受限的本地超时。诚实地记录妥协行为。一起更新目录、工具目录、指南和锁。

保留原始和第三方通知。新的原始文件带有 `Copyright 2026 Mattia Piazzalunga` 和 `SPDX-License-Identifier: LicenseRef-PolyForm-Shield-1.0.0`。贡献使用 PolyForm-Shield-1.0.0.。记录适当的归属信息，但不要声称上游所有权。请勿提交凭证、私人文件、虚拟环境或依赖目录。

仅在您拥有必要权利时，才能在 PolyForm Shield 1.0.0 下贡献原创代码。保留第三方条款并标明任何单独授权的材料。有关允许使用情况和竞业限制，请参阅 [ 许可摘要 ](docs/licenses.md)。本指南本身并不转让版权或授予单独的重新许可协议。

关于开源 (PolyForm Shield 1.0.0) 核心和贡献的问题：[developers@onekit.org](mailto:developers@onekit.org)。一般支持：[support@onekit.org](mailto:support@onekit.org)。
