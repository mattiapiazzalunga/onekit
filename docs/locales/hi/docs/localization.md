# CLI का स्थानीयकरण

भाषा: `en`, `it`, `fr`, `es`, `de`, `ru`, `zh` (सरलीकृत चीनी), `pt` (पुर्तगाली), `hi` (हिंदी)। `onekit --language it ...` या `ONEKIT_LANGUAGE=it` के साथ एक का चयन करें। ऑपरेटिंग सिस्टम लोकेल का उपयोग तब किया जाता है जब न तो सेट किया जाता है। असमर्थित स्थानीय लोग अंग्रेजी का उपयोग करते हैं। कमांड नाम, विकल्प कुंजी, पथ, प्रारूप पहचानकर्ता और मशीन पठनीय JSON अनुबंध स्थिर रहते हैं। मानव सहायता, स्थिति, चेतावनी और ज्ञात त्रुटियों को स्थानीयकृत किया जाता है। बाह्य इंजन निदान अपने अपस्ट्रीम टेक्स्ट को बनाए रखते हैं।

प्रत्येक व्यक्ति या AI एक उपकरण को जोड़ने या बदलने के लिए MUST उसी परिवर्तन में सभी नौ प्रस्तुति सूची को अपडेट करता है। नाम, मदद, विवरण, त्रुटि संदेश, नोटिस, README और उपकरण प्रलेखन एक से एक पत्राचार में रहना चाहिए। अंग्रेजी के साथ एक शॉर्टकट के रूप में लापता अनुवाद नहीं भरें। प्लेसहोल्डर, कोड उदाहरण, यूआरएल और कानूनी रूप से आवश्यक क्रियाशील नोटिस को बरकरार रखें। संदर्भ में अर्थ और शब्दावली की समीक्षा करें।

कैटलॉग: `src/onekit/locales/{language}.json`। प्रस्तुति कोड: `i18n.py`। अंग्रेजी संदेश सामान्य कुंजी हैं; प्रसंस्करण एल्गोरिदम स्वतंत्र रहते हैं। स्वतंत्र भाषा रजिस्ट्री `src/onekit/locales/languages.json` है, जिसमें ऑपरेटिंग सिस्टम उपनाम शामिल हैं। एक रजिस्ट्री प्रविष्टि और एक पूर्ण सूची को एक साथ जोड़ें। समीक्षित शब्दावली `scripts/localization-reviewed.json` में दर्ज की गई है; इसे लेखा परीक्षा से पहले `python scripts/apply_localization_review.py src/onekit/locales` के साथ लागू करें।

1. अपनी मूल फ़ाइल में अंग्रेजी संदेश या प्रलेखन संपादित करें।
2. `python scripts/localization_inventory.py` रन।
3. प्रत्येक अन्य भाषा सूची को अपडेट करें और अप्रचलित प्रविष्टियों को हटा दें। लेखन स्क्रिप्ट अनुवाद तैयार कर सकते हैं; उत्पन्न पाठ की समीक्षा की आवश्यकता होती है।
4. `python scripts/audit_localization.py` और `pytest tests/test_i18n.py` भागो।
5. `docs/locales/{language}/` के तहत स्थानीयकृत Markdown को फिर से उत्पन्न करने के लिए `python scripts/localize_docs.py` रन बनाए, मूल सापेक्ष दस्तावेज़ संरचना को बनाए रखा।

ऑफलाइन राइटिंग कमांड एक स्थानीय Argos मॉडल निर्देशिका लेता है जिसके बाद कैटलॉग निर्देशिका होती है। CTranslate2 और SentencePiece अनुवाद तैयार करने की निर्भरताएँ हैं, CLI रनटाइम की आवश्यकताएँ नहीं। CLI किसी अनुवाद सेवा से संपर्क नहीं करता है।

CLI के अनुवाद और प्रलेखन को किसी भी वेबसाइट से स्वतंत्र रूप से बनाए रखा जाता है जो प्रसंस्करण पुस्तकालय को एम्बेड करता है। केवल सार्वजनिक उपयोग लिंक यहाँ हैं।
