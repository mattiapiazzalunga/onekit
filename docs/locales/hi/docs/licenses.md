# ओपन सोर्स (PolyForm Shield 1.0.0)

आप वाणिज्यिक और आंतरिक उपयोग सहित अनुमत उद्देश्यों के लिए कोर का उपयोग, संशोधित और पुनर्वितरण कर सकते हैं। आप सॉफ्टवेयर के साथ प्रतिस्पर्धा करने वाले एक उत्पाद या सेवा प्रदान करने के लिए इसका उपयोग नहीं कर सकते हैं या किसी उत्पाद के साथ लाइसेंसर या इसके सहयोगी सॉफ्टवेयर का उपयोग करके प्रदान करते हैं; मुफ्त पेशकश और विभिन्न प्लेटफार्मों या इंटरफेस भी प्रतिस्पर्धा कर सकते हैं। जब प्रतियां साझा करते हैं, तो लाइसेंस टेक्स्ट या इसके URL और सॉफ़्टवेयर के साथ आपूर्ति की गई किसी भी आवश्यक सूचना लाइन शामिल है। पूर्ण लाइसेंस नए और बंद उत्पादों, पेटेंट शर्तों और वारंटी अस्वीकरण के लिए अपने अपवाद सहित नियंत्रित करता है। यहां, "ओपन सोर्स (PolyForm Shield 1.0.0)" इन शर्तों के तहत प्रकाशित स्रोत का वर्णन करता है; गैर-प्रतियोगिता प्रतिबंध का मतलब है कि यह ओपन सोर्स डेफिनिशन के तहत अप्रतिबंधित ओपन सोर्स के बजाय स्रोत-उपलब्ध सॉफ़्टवेयर है।
