# डिजिटल हस्ताक्षर सत्यापन

CLI और ब्राउज़र उसी Python सत्यापन इंजन को निष्पादित करता है। कोई दस्तावेज अपलोड नहीं किया जाता है। यूरोपीय संघ के ट्रस्ट-लिस्ट हस्ताक्षर और समाप्ति की जांच की जाती है; समर्थित सेवाओं को बाहर रखा जाता है।

क्रिप्टोग्राफ़िक अखंडता और ADES सत्यापन अलग परिणाम हैं। मान्यता स्थानीय साक्ष्यों का उपयोग करती है और यूरोपीय संघ के ट्रस्ट सूचियों को प्रमाणित करती है। मिसिंग साक्ष्य अनिश्चित है। DSS के साथ समतुल्यता प्रमाणित नहीं है।

स्थानीय रूप से ADES सत्यापन के साथ PDF और CMS हस्ताक्षरों की जाँच करें। अलग हस्ताक्षर मूल फ़ाइल की आवश्यकता होती है। वैकल्पिक रूप से एक हस्ताक्षर साक्ष्य ZIP जोड़ें। मिसिंग ट्रस्ट या रिवोकेशन साक्ष्य एक अनिश्चित परिणाम देता है।

इस आदेश के साथ सार्वजनिक ट्रस्ट सूचियों को ताज़ा करें। यह कोई दस्तावेज या हस्ताक्षरकर्ता डेटा नहीं भेजता है।

```sh
python -m pip install "onekit-tools[verification,trustlists]"
python -m onekit.signature_evidence eu-trust-lists.zip
onekit run signature-verify signed.pdf eu-trust-lists.zip -o report
```

सबूत ZIP प्रकट निम्नलिखित संरचना का उपयोग करता है। अनुपूरक प्रमाणपत्र कभी भी मनमाने विश्वास एंकर नहीं बनते हैं।

```json
{"schema":"onekit-signature-evidence-v1","lotl":"lotl.xml","trusted_lists":[{"url":"https://official.example/list.xml","path":"tl/list.xml"}],"certificates":[],"crls":[],"ocsps":[]}
```

नेटिव Windows ARM64 Python को क्रिप्टोग्राफी के लिए टूल बनाने की आवश्यकता हो सकती है। x64 Python का उपयोग करें जब एक द्विआधारी wheel अनुपलब्ध है।

वर्तमान स्नैपशॉट में 30 क्षेत्र शामिल हैं। समर्थित TakenOverBy एक्सटेंशन सेवा इतिहास को संरक्षित करते हैं और किसी अन्य प्रदाता को विश्वास हस्तांतरण नहीं करते हैं।

एल्गोरिथ्म स्वीकृति ने पिन्ड डीएसएस 6.5.1 थ्रेसहोल्ड का उपयोग किया; गणितीय अखंडता को अलग से बताया गया है।

Windows को ट्रस्टलिस्ट अतिरिक्त ऑपरेटिंग सिस्टम सर्टिफिकेट स्टोर के माध्यम से सत्यापित TLS सक्षम बनाता है।

ट्रस्ट स्नैपशॉट का आंशिक कवरेज है। मिसिंग साक्ष्य अनिश्चित रहता है। चयनित डीएसएस संदर्भ परीक्षण थकाऊ eIDAS या PADES समतुल्यता की स्थापना नहीं करते हैं।
