# छवि प्रभाव

```sh
onekit run image-effects photo.jpg --options '{"effect":"pixelate","strength":16}' -o output
onekit run image-effects photo.jpg --options '{"effect":"blur","strength":12,"scope":"selected","regions":[{"x":0.1,"y":0.2,"width":0.3,"height":0.25}]}' -o output
```

`strength` 1 से 100 पिक्सेल (पिक्सेलेशन के लिए कम से कम 2) तक एक पूर्णांक है। `scope` `all` (डिफ़ॉल्ट) या `selected` है; चयनित मोड को सामान्यीकृत 0-1 निर्देशांक और वैकल्पिक `page: 1` के साथ 1-500 आयतों की आवश्यकता होती है। `color` ठोस कवर के लिए `#RRGGBB` का उपयोग करता है। तीव्रता ग्रेस्केल या ठोस कवर पर कोई प्रभाव नहीं पड़ता है। ओवरलैपिंग क्षेत्रों को मूल पिक्सल से संसाधित किया जाता है, बिना संचयी ब्लर के। 80 मिलियन से अधिक चयनित पिक्सल संसाधित किए जाते हैं, जो ओवरलैप की गिनती करते हैं।

ब्लूर और पिक्सेलेशन दृश्य प्रभाव हैं और संवेदनशील विवरण को हटाने की गारंटी नहीं दे सकते हैं। जब सामग्री को अपरिवर्तनीय रूप से कवर किया जाना चाहिए तब स्थायी छवि रिडैक्शन का उपयोग करें।
