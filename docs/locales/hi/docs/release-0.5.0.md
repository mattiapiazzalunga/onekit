# OneKit 0.5.0

ऑफ़लाइन CLI और Python प्रसंस्करण API की प्रारंभिक रिलीज दस्तावेजों, पीडीएफ, छवियों, मीडिया, अभिलेखागार, फोंट, डेवलपर उपयोगिताओं, QR कोड, लाइसेंस घोषणाओं और फ़ाइल निरीक्षण के लिए 230 उपकरणों के साथ। बेस इंस्टॉलेशन में कोई रनटाइम निर्भरता नहीं है; वैकल्पिक अतिरिक्त और बाहरी इंजन चयनित उपकरणों को सक्षम करते हैं।

सीमित इनपुट सत्यापन, पुन: प्रयोज्य वर्कफ़्लोज़, स्थानीय निर्भरता सेटअप, प्रारूप-विशिष्ट प्रसंस्करण अनुबंध और स्रोत आधारित लाइसेंस निरीक्षण शामिल है। लाइसेंस रिपोर्ट असत्यापित अनुमानों को बनाए रखती है जिसके लिए मैनुअल समीक्षा की आवश्यकता होती है।

प्रदर्शन अद्यतन अपारदर्शी छवि तैयारी और पाठ निरीक्षण में तेजी लाने। अप्रयुक्त आयात और अनावश्यक डेवलपर-इंजिन असाइनमेंट को हटा दिया गया है।

मॉडल इंजन वैकल्पिक हैं: जरूरत पड़ने पर `background` या `transcription` अतिरिक्त स्थापित करें। U2Net सीधे ONNX रनटाइम और एक चेकसम सत्यापित कैश मॉडल के साथ चलता है। Whisper faster-whisper का उपयोग करता है। फ़ाइल स्थानीय रहती हैं; पहली रन डाउनलोड मॉडल वजन। वीडियो प्रोसेसिंग के लिए FFmpeg और ffprobe की आवश्यकता होती है। वीडियो डाउनलोडिंग अलग `video` अतिरिक्त का उपयोग करता है।

अद्यतन 13 करने के लिए Pillow और प्रमाणित ताला प्रकाशित सलाहकारों को संबोधित करने के लिए। पोर्टेबल `all` अतिरिक्त मॉडल इंजन और हस्ताक्षर से अलग रहता है।
