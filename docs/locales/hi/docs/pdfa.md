# PDF/A रूपांतरण और सत्यापन

CLI और Python API कॉल `onekit.tools.pdfa`. यह मॉड्यूल कोई निष्पादन योग्य प्रोग्राम नहीं चलाता और कोई नेटवर्क कनेक्शन नहीं खोलता। रूपांतरण फ़ॉन्ट्स, रंग और सामान्यीकरण के लिए pdftopdfa 0.9.24 का उपयोग करता है, इसके बाद pikepdf 10.17.0 PDF/A तैयारी और सटीक अंतिम बाइट्स की मान्यता प्राप्त होती है। कोई Ghostscript निर्भरता नहीं है।

रूपांतरण PDF/A-2b (डिफ़ॉल्ट) और 3b का समर्थन करता है। सत्यापन 1b, 2b और 3b का समर्थन करता है। ए / यू अनुरूपता, PDF/A-4 और OCR इस एडाप्टर के बाहर हैं। Unsupported रचनाएं `not_checked` हैं, जो अनुपालन नहीं करते हैं। इस रूढ़िवादी अनुमति सूची से एक `pass` एक अभिलेखीय प्रमाणन नहीं है; स्वतंत्र veraPDF सत्यापन संस्थागत प्रस्तुतियों के लिए सिफारिश की गई है।

```
onekit run pdf-to-pdfa input.pdf --options '{"profile":"2b"}' -o output
onekit run pdf-validate-pdfa output/input.pdf -o report
onekit doctor pdf-to-pdfa --json
```

CLI स्वचालित रूप से एक pinned स्थापित करता है, की समीक्षा की **non-OCR स्तर-B subset** अपस्ट्रीम पैकेज के. यह जानबूझकर पैडलओसीआर, ओसीआरमीपीडीएफ या पीडीएफमिनर के अप्रयुक्त PDF पार्सर के लिए क्रिप्टोग्राफ़ी बैकएंड को स्थापित नहीं करता है: कोई विकल्प अपस्ट्रीम OCR या ए / यू टैगिंग एपीआई के लिए आगे नहीं बढ़े हैं। अपस्ट्रीम `pdftopdfa` wheel को अनमोल बनाया गया है। इसके पैकेज मेटाडाटा में एपीआई OneKit के लिए व्यापक आवश्यकताओं को शामिल किया गया है। वैकल्पिक `[pdfa]` अतिरिक्त समीक्षा की गई पूर्वापेक्षाओं को स्थापित करता है। प्रत्यक्ष Python API उपयोग के लिए, उस अतिरिक्त और उसके बाद `pip install --no-deps pdfminer.six==20260107 pdftopdfa==0.9.24` स्थापित करें। इस एडाप्टर के लिए अपस्ट्रीम के OCR एक्स्ट्रास को स्थापित न करें। अपस्ट्रीम की अनिवार्य OCR आवश्यकताएं वर्तमान में OneKit के साथ संगत एक पुराने PyYAML पिन करती हैं। रूपांतरण के लिए Python 3.12+ की आवश्यकता है; स्टैंडअलोन सत्यापन Python 3.11+ पर काम करता है। चयनित रनटाइम का ऑडिट करने के लिए `python scripts/check_licenses.py --include-pdfa` चलाएं।

पूर्व `icc_profile` विकल्प एक वैकल्पिक स्थानीय ICC फ़ाइल के रूप में स्वीकार किए जाते हैं; डिफ़ॉल्ट कनवर्टर की बंडल, लाइसेंस प्राप्त RGB/CMYK प्रोफाइल को संरक्षित करता है। एन्क्रिप्टेड PDF और डिजिटल हस्ताक्षर रूपांतरण द्वारा अस्वीकार कर दिए गए हैं। रूपांतरण फोंट को प्रतिस्थापित कर सकता है और गैर-आर्किटिव क्रियाओं या मेटाडाटा को हटा सकता है; चेतावनी सफल आउटपुट के साथ होती है। असफल या अपूर्ण रूप से जाँच उम्मीदवारों को कभी परिवर्तित PDF/A फ़ाइलों के रूप में वापस नहीं किया जाता है। इनपुट ओवरराइट नहीं होते हैं। JSON सत्यापन रिपोर्ट `compliant` और `reports` फ़ील्ड को संरक्षित करती है और चेक प्रोफाइल, फैसले और इंजन जोड़ती है।
