# रंग, फोटो बहाली और PDF फॉर्म

ये उपकरण मानक `onekit run TOOL ... --options JSON` कमांड और Python `execute` API के माध्यम से उजागर होते हैं। इनपुट / आउटपुट तर्कों के लिए `onekit run --help` देखें। नीचे दिए गए सभी निर्देशांक EXIF अभिविन्यास या घूर्णन के बाद प्रदर्शित PDF पृष्ठ के बाद छवि का उल्लेख करते हैं।

- `color-picker`: एक UTF-8 फ़ाइल का निरीक्षण करें जिसमें `#RRGGBB` शामिल हैं, या पूर्णांक पिक्सेल विकल्प `x` और `y` (डिफ़ॉल्ट द्वारा केंद्र) के साथ एक छवि का नमूना लें। HEX, RGB, OKLCH, ब्लैक/व्हाइट टेक्स्ट कॉन्ट्रास्ट और मूल RGBA छवियों के लिए रिपोर्ट करता है। दृश्यमान रंग सफेद रंग पर मिश्रित होते हैं।
- `image-extract-colors`: `colors` (2-32, डिफ़ॉल्ट 6)। एक थंबनेल का माध्य-कट मात्राकरण 256 × 256 से घिरा हुआ है। पूरी तरह से पारदर्शी पिक्सल को बाहर रखा गया है; आंशिक अल्फा सफेद रंग पर मिश्रित है। फ्रैक्शन इस नमूने का वर्णन करते हैं।
- `jpg-to-svg`: `colors` (2-32, डिफ़ॉल्ट 16), `resolution` (32-512, डिफ़ॉल्ट 256)। एक सीमाबद्ध छवि को क्वांटाइज़ करता है, क्षैतिज बराबर रंग को लंबवत रूप से चलाता है, और भरे हुए SVG पथ लिखते हैं। कोई बिटमैप एम्बेडेड नहीं है। यह वेक्टर टाइल्स को एक पोस्टरीकृत उपस्थिति के साथ पैदा करता है, जो चिकनी वक्र ट्रेसिंग नहीं है।
- `image-repair`: `regions` के बिना, अलग-अलग धब्बों के लिए `size` 3 या 5 का मीडियन फ़िल्टर लागू होता है। क्षेत्रों के साथ, निश्चित आसपास के पिक्सल और असतत हार्मोनिक प्रसार (`iterations` 10-500, डिफ़ॉल्ट 200) का उपयोग करके चयनित पिक्सेल को पुनर्निर्माण करता है।
- `image-remove-watermark`: `regions` की आवश्यकता है; उसी स्थानीय पुनर्निर्माण का उपयोग करता है। यह लापता पिक्सल का अनुमान लगाता है और छिपी हुई मूल सामग्री को ठीक नहीं कर सकता है। बनावट, बड़े निशान और जटिल पृष्ठभूमि खराब परिणाम दे सकते हैं।
- `image-sharpen`: `method` `unsharp` (डिफ़ॉल्ट) या `deconvolution` है। `radius` 0.3-5 unsharp त्रिज्या सेट करता है या अनुमान लगाया गया Gaussian बिंदु फैलता है। Unsharp `amount` 0-300 प्रतिशत (डिफ़ॉल्ट 150)। रिचर्डसन-लुसी 1-30 `iterations` (डिफ़ॉल्ट 10) का उपयोग करता है, पैडिंग और एफएफटी को दस लाख स्रोत पिक्सल तक प्रतिबिंबित करता है। यह Gaussian धुंध को मानता है और मनमाने ढंग से गति को सही नहीं करता है। दोनों ही शोर और हेलो को बढ़ा सकते हैं।
- `pdf-remove-watermark`: डिफ़ॉल्ट `mode: "remove"` हटाना `/Artifact` समूह टैग `/Subtype /Watermark` (नामित संपत्ति संसाधनों सहित) और `/Watermark` एनोटेशन वैकल्पिक `text` व्हाइटस्पेस सामान्यीकृत, उनके फ़ॉन्ट एन्कोडिंग / ToUnicode मानचित्र के माध्यम से glyphs decoding के साथ पूर्ण टेक्स्ट ऑब्जेक्ट्स से मेल खाता है। नेस्टेड फॉर्म XObjects को बार-बार संसाधित किया जाता है। उपयोग `mode: "inspect"` प्राप्त करने के लिए JSON पाठ, छवि और फॉर्म इनवोकेशन आईडी की रिपोर्ट; चयनित ID को पास करें `objects` मोड को हटाने में। एक रूप का चयन करने से अपने पूरे ग्राफिक समूह को हटा दिया जाता है। संशोधित रूपों को प्रति दीक्षा की प्रतिलिपि बनाई जाती है, इसलिए साझा संसाधन का अचयनित उपयोग अपरिवर्तित रहता है। IDs एक ही मूल को संदर्भित करता है PDF और परिवर्तन के बाद निरीक्षण किया जाना चाहिए। यह ड्राइंग-ऑब्जेक्ट हटाने वाला है, जो रिडैक्शन को सुरक्षित नहीं करता है: अप्रयुक्त संसाधन वस्तुएं आउटपुट में रह सकती हैं। यह स्वचालित रूप से एक वॉटरमार्क के रूप में मनमाने ढंग से untagged सामग्री की पहचान नहीं करता है, और स्कैन किए गए छवि में विलय होने वाले चिह्न को उस छवि से अलग नहीं किया जा सकता है। एक रिपोर्ट में 2,000 उम्मीदवारों को शामिल किया गया है, पुनरावृत्ति 12 स्तरों तक सीमित है और 300,000 ड्राइंग ऑपरेशनों को संसाधित की जाती है। शून्य मैच एक स्पष्ट त्रुटि पैदा करता है।
- `pdf-make-fillable`: `fields` अद्वितीय ASCII `name`, `type` (`text`, `checkbox`, `choice`), 1-आधारित `page`, सामान्यीकृत `x`, `y`, `width`, `height` के साथ मानक AcroForm विगेट्स की एक JSON सरणी है। वैकल्पिक `required`, पाठ `multiline` और पसंद `choices` समर्थित हैं। मौजूदा क्षेत्रों और पृष्ठ सामग्री को संरक्षित किया जाता है। डुप्लिकेट नाम, एन्क्रिप्टेड PDF और XFA को खारिज कर दिया गया है। कोई स्वचालित रिक्त मान्यता नहीं है।

छवि क्षेत्र `{"page":1,"x":0.2,"y":0.3,"width":0.1,"height":0.05}` जैसे वस्तुओं की सरणी हैं। निर्देशांक को 0-1 तक शीर्ष बाएं से सामान्यीकृत किया जाता है। पुनर्निर्माण अधिकतम 100 आयतों, छवि के अधिकतम 35% क्षेत्र और पैडिंग सहित दस लाख पिक्सल के बाउंडिंग बॉक्स का समर्थन करता है। मुखौटा परिवर्तनों के अंदर केवल RGB; मूल अल्फा बनाए रखा गया है। आउटपुट PNG होते हैं, जिनमें स्रोत मेटाडेटा नहीं होता। एनिमेटेड/multiframe छवियों को अस्वीकार कर दिया गया है। सामान्य छवि डिकोडिंग 40 मिलियन पिक्सेल तक सीमित है। PDF 256 पृष्ठों तक सीमित हैं और 200 नए क्षेत्रों के लिए फॉर्म बनाते हैं।

उदाहरण Python उपयोग:

```python
from onekit import Artifact, execute

result = execute("pdf-make-fillable", [Artifact("source.pdf", pdf_bytes)], {
    "fields": [{"name": "Name", "type": "text", "page": 1,
                "x": 0.1, "y": 0.2, "width": 0.4, "height": 0.05}]
})
```

परिणामस्वरूप फ़ाइलों की समीक्षा करें और मूल सिद्धांतों को बनाए रखें। एक संगत PDF पाठक को फॉर्म भरने और सहेजने की आवश्यकता है।
