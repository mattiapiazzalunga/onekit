# स्थायी लालित्य

<a id="pdf"></a>
## PDF

प्रत्येक पृष्ठ को प्रस्तुत किया जाता है, चयनित पिक्सल को अपारदर्शी ब्लैक के साथ बदल दिया जाता है और एक नया PDF पहले से रिडैक्ट की गई छवियों से बनाया जाता है। कोई मूल PDF ऑब्जेक्ट कॉपी नहीं किया जाता है। यह मूल चयन योग्य पाठ को हटा देता है, OCR परतें, छिपी हुई परतें, फार्म फ़ील्ड्स, एनोटेशन/कॉममेंट ऑब्जेक्ट्स, लिंक्स, स्क्रिप्ट्स, अटैचमेंट्स, मेटाडाटा, थंबनेल और आउटपुट से क्रमिक सेव का इतिहास। दृश्यमान एनोटेशन उपस्थिति पिक्सेल में चपटा जाता है इसलिए एक मौजूदा अपारदर्शी एनोटेशन अप्रत्याशित रूप से उस सामग्री को प्रकट नहीं करता है जो इसे कवर करती है। फील्ड / एनोटेशन उपस्थिति अंतर के लिए पूर्वावलोकन की समीक्षा करें; कोई इंटरैक्टिव ऑब्जेक्ट बनाए नहीं रखा जाता है। अनचयनित दृश्य पृष्ठ सामग्री पिक्सेल के रूप में बनी हुई है।

<a id="images"></a>
## चित्र

पिक्सेल को एक नए अपारदर्शी RGB PNG को एन्कोड करने से पहले ठोस काले रंग के साथ बदल दिया जाता है। इसमें कोई हटाने योग्य ओवरले, मूल परत या इनकोडेड क्षेत्रों में मूल अनमास्क पिक्सेल डेटा नहीं है। स्रोत EXIF, GPS, XMP, टिप्पणियां, प्रोफाइल, थंबनेल और अन्य मूल मेटाडाटा की प्रतिलिपि नहीं है। ट्रांसपेरेंसी को सफेद रंग पर मिश्रित किया जाता है, जो पारदर्शी पिक्सल के तहत छिपे हुए RGB मानों को त्याग देता है। EXIF अभिविन्यास क्षेत्रों की व्याख्या करने से पहले लागू किया जाता है। एनिमेटेड और बहु-फ्रेम इनपुट को अस्वीकार कर दिया जाता है इसलिए अतिरिक्त फ़्रेम बिना रिडैक्शन के नहीं रह सकते; पहले एक फ्रेम निर्यात करें।

<a id="cli-and-workflows"></a>
## CLI और वर्कफ़्लो

PDF रिडैक्शन के लिए `onekit-tools[pdf]` या छवियों के लिए `onekit-tools[images]` इंस्टॉल करें। दोनों उपकरण `regions` को स्वीकार करते हैं, आयतों की एक सरणी वैकल्पिक रूप से JSON स्ट्रिंग के रूप में क्रमबद्ध होती है। प्रत्येक आयत में `page` (एक आधारित, डिफ़ॉल्ट 1), `x`, `y`, `width`, `height`) हैं। निर्देशांक दृष्टि से उन्मुख पृष्ठ / छवि के भिन्न होते हैं, जो शीर्ष बाईं ओर उत्पत्ति के साथ होते हैं: `0.1` का मतलब 10% है। छवियों के लिए, `page` होना चाहिए 1. 500 आयत तक का चयन किया जा सकता है। बाउंड्स को पृष्ठ के अंदर फिट होना चाहिए; मास्क राउंड आउटवर्ड और एक आउटपुट पिक्सेल का विस्तार आंशिक किनारों को कवर करने के लिए करना चाहिए।

```sh
onekit run pdf-redact private.pdf -o redacted.pdf --options '{"regions":[{"page":1,"x":0.1,"y":0.2,"width":0.5,"height":0.1}],"dpi":200}'
onekit run image-redact private.jpg -o redacted.png --options '{"regions":[{"x":0.2,"y":0.2,"width":0.3,"height":0.2}]}'
```
