# रिलीज परिचालन

`main` और स्थिर `v*` टैग की रक्षा करें। Repository `onekit`, वर्कफ़्लो `release.yml` और पर्यावरण `pypi` के लिए PyPI ट्रस्टेड प्रकाशक पंजीकृत करें। पैकेज संस्करण, लॉकफ़ाइल, कैटलॉग और प्रलेखन अद्यतन करें, फिर एक समीक्षित प्रतिबद्धता से मिलान स्थिर SemVer टैग प्रकाशित करें।

रिलीज वर्कफ़्लो टैग को सत्यापित करता है, रनों की आवश्यकता CLI चेक और प्रकाशित करती है सार्वभौमिक wheel / स्रोत वितरण, जीएचसीआर छवि और GitHub रिलीज़ एसेट। `onekit-release.json` में संस्करण, स्रोत प्रतिबद्ध, परिसंपत्ति चेकसम और डाउनलोड यूआरएल शामिल हैं। प्रकाशन के लिए मौजूदा अचल संपत्तियों को संरक्षित करना चाहिए; कोड परिवर्तन के लिए एक नया संस्करण की आवश्यकता होती है।

<a id="pypi-license-metadata"></a>
## PyPI लाइसेंस मेटाडेटा

PyPI पैकेज ओपन सोर्स (PolyForm Shield 1.0.0) है, जिसमें इसके प्रोजेक्ट पेज पर प्रदर्शित README में वर्णित गैर-प्रतियोगिता प्रतिबंध है। `project.license` `LicenseRef-PolyForm-Shield-1.0.0` का उपयोग करता है; wheel और स्रोत संग्रह में पूर्ण LICENSE और नोटिस शामिल हैं। परियोजना मेटाडाटा लाइसेंस और प्रलेखन के लिए लिंक करता है। OSI-approved लाइसेंस क्लासिफायर को न जोड़ें: यह लाइसेंस प्रतिस्पर्धी उत्पादों को प्रतिबंधित करता है।

प्रकाशन से पहले, उद्देश्यपूर्ण रिलीज से निर्माण करना और वास्तविक कलाकृतियों को मान्य करना:

```sh
uv build
python scripts/check_distribution_licenses.py
```

सीआई और रिलीज बिल्ड ने कलाकृतियों को प्रकाशित करने से पहले इस चेक को चलाया। PyPI पैक किए गए README को प्रस्तुत करता है, इसलिए प्रलेखन या लाइसेंस मेटाडाटा बदलने के बाद पुनर्निर्माण की आवश्यकता होती है। पहले से ही प्रकाशित रिलीज़ की जगह एक नया, अप्रयुक्त संस्करण प्रकाशित करें; मौजूदा PyPI वितरण को ओवरराइट नहीं किया जा सकता है। पहले वितरित संस्करण अपने मूल लाइसेंसिंग शर्तों को बनाए रखते हैं। वर्तमान चेकआउट का संस्करण स्वचालित रूप से लाइसेंस परिवर्तन द्वारा उन्नत नहीं है।

परियोजना मालिक PyPI खाते, ट्रस्टेड प्रकाशक और प्रकाशन को अलग से कॉन्फ़िगर करता है; स्थानीय तैयारी पैकेज अपलोड नहीं करती है या लाइव PyPI पेज बदलती है।

<a id="weekly-dependency-maintenance"></a>
## निर्भरताओं का साप्ताहिक रखरखाव

आश्रितबॉट यूवी लॉकफ़ाइल, CLI नोड इंजन निर्भरता, डोकर और GitHub एक्शन की निगरानी करता है। अनुसूचित चेक वर्कफ़्लो लॉक निर्भरता और देशी इंजन का परीक्षण करता है। योग्य Python लॉक-केवल अपडेट सफल जांच और शाखा संरक्षण के अधीन रहते हैं।
