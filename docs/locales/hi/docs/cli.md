# CLI संदर्भ

PDF टेक्स्ट वॉटरमार्क जोड़ने के लिए `onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"CONFIDENTIAL","opacity":0.25}'` का उपयोग करें। स्थिति, रोटेशन, पृष्ठ रेंज और बार-बार लेआउट के लिए [ वॉटरमार्क गाइड](watermark.md) देखें।

स्थायी रिडैक्शन `onekit run pdf-redact` और `onekit run image-redact` के रूप में उपलब्ध है, जिसमें चयन योग्य क्षेत्रों को `regions` के माध्यम से आपूर्ति की जाती है। एक्सपोर्ट की गई फ़ाइलों के निर्देशांक, रास्टराइज़ेशन और गोपनीयता गारंटी के लिए [redaction गाइड](redaction.md) देखें।

JavaScript नियमित अभिव्यक्तियों का परीक्षण करने के लिए `onekit run dev-regex-test input.txt -o regex-results.json --options '{"pattern":"[0-9]+","flags":"g"}'` का उपयोग करें। Node.js की आवश्यकता है; कैप्चर, प्रतिस्थापन और निष्पादन सीमा के लिए [regex परीक्षक गाइड](regex.md) देखें।

मानक बारकोड `onekit run text-to-barcode`, `onekit run scan-barcode` और `onekit run barcode-to-text` के माध्यम से उपलब्ध हैं। `barcode` या `qrcode` अतिरिक्त स्थापित करें। [barcode सेटिंग्स और समर्थित मानकों](qrcode.md#standard-linear-barcodes) देखें।

`onekit --version` कोर संस्करण की रिपोर्ट करता है। `python -m onekit` एक ही CLI को बुलाता है।

| कमान | बेहावर |
| --- | --- |
| `onekit list [--group GROUP] [--json]` | उपकरण, अनुबंध, उपलब्धता और निष्ठा की खोज करें। |
| `onekit doctor [TOOL_ID] [--json]` | Python पैकेज, इंजन और लाइसेंस-पॉलिसी ब्लॉकों की जाँच करें। |
| `onekit run TOOL_ID INPUTS -o OUTPUT` | प्रक्रिया फ़ाइलों; एन्क्रिप्शन भी निर्देशिका स्वीकार करता है। |
| `onekit pipeline --steps WORKFLOW INPUTS -o OUTPUT` | एक JSON फ़ाइल से 1-16 ऑर्डर किए गए टूल चरणों को निष्पादित करें। |
| `onekit engines install [--directory DIRECTORY]` | बंद नोड डेवलपर इंजन स्थापित करें; नोड / एनपीएम की आवश्यकता है। |
| `onekit download URL -o OUTPUT [--quality best\|720\|1080] [--force]` | yt-dlp के माध्यम से एक वीडियो डाउनलोड करें; इंटरनेट और FFmpeg की आवश्यकता है। |

`run` एक JSON वस्तु, `--ask-password` और `--force` के साथ `--options` स्वीकार करता है। पाइपलाइन पासवर्ड संकेत का समर्थन करते हैं और झंडे को भी ओवरराइट करते हैं। एक आउटपुट के लिए फ़ाइल नाम या कई आउटपुट के लिए निर्देशिका का उपयोग करें। विस्तार रहित गंतव्य निर्देशिकाएँ हैं। टकराने वाले आउटपुट नाम अस्वीकार किए जाते हैं।

<a id="local-agents-and-automation"></a>
## स्थानीय एजेंट और ऑटोमेशन

**आपका CLI आपका एजेंटिक CLI.* * OneKit आपके टर्मिनल पर और स्थानीय AI एजेंटों के लिए एक फ़ाइल-प्रोसेसिंग टूलकिट के रूप में उपयोगी है जो शेल कमांड या लॉन्च सबप्रोसेस को निष्पादित कर सकते हैं। एक एजेंट उपकरण अनुबंधों की खोज कर सकता है, आवश्यकताओं की जांच कर सकता है और चयनित ऑपरेशन चला सकता है और इसकी आउटपुट फ़ाइलों का निरीक्षण कर सकता है।

```sh
onekit list --json
onekit doctor pdf-merge --json
onekit run pdf-merge first.pdf second.pdf -o combined.pdf
onekit pipeline --steps workflow.1kit input.pdf -o output/
```

`list --json` उपकरण IDs, स्वीकृत इनपुट, आउटपुट प्रारूपों, विकल्प, सीमा और निष्ठा नोट्स को उजागर करता है। `doctor TOOL_ID --json` ने तत्परता, लापता निर्भरता और लाइसेंस-पॉलिसी ब्लॉकों की रिपोर्ट की। इन JSON प्रतिक्रियाओं को मानव पठनीय लिस्टिंग के बजाय पार्स करें। `run` और `pipeline` अपने परिणामों को `-o` के साथ आपूर्ति की गई गंतव्य पर लिखते हैं; उनके पास एक सामान्य `--json` प्रतिक्रिया ध्वज नहीं है। कुछ उपकरण JSON रिपोर्ट फ़ाइलों का उत्पादन करते हैं।

एक स्थानीय एजेंट के लिए, पहले उपकरण की खोज करें, इसकी आवश्यकताओं की जांच करें, फिर इसे स्पष्ट पथ और JSON ऑब्जेक्ट के साथ `--options` में कॉल करें जहां आवश्यक हो। बिना शेल कोट्स के पथ और JSON को संरक्षित करने के लिए एक सूची के रूप में उप-प्रक्रिया तर्कों को पास करें। आउटपुट लेने से पहले निकास स्थिति की जांच करें:

| एक्ज़िट कोड | अर्थ |
| --- | --- |
| `0` | कमांड ने सफलतापूर्वक पूरा किया। |
| `1` | `doctor` लापता आवश्यकताओं या एक पॉलिसी ब्लॉक पाया; रिपोर्ट का निरीक्षण करें। |
| `2` | अमान्य तर्क या एक प्रसंस्करण / इनपुट / आउटपुट त्रुटि; stderr पढ़ा। |
| `130` | कमांड एक कीबोर्ड बाधा के साथ रद्द कर दिया। |

प्रत्येक नौकरी के लिए एक नया आउटपुट पथ चुनें; मौजूदा आउटपुट को तब तक संरक्षित किया जाता है जब तक कि `--force` की आपूर्ति नहीं की जाती। `--ask-password` को एक इंटरैक्टिव टर्मिनल की आवश्यकता होती है। unattended रन से पहले निर्भरता और मॉडल कैश तैयार करें: लापता घटक स्वचालित सेटअप और नेटवर्क डाउनलोड को ट्रिगर कर सकते हैं, और कुछ मूल इंस्टॉलरों को बातचीत या उच्च विशेषाधिकार की आवश्यकता होती है। नेटवर्क उपकरण भी अपने अनुरोध स्रोतों से संपर्क करें।

फ़ाइल प्रोसेसिंग आपकी मशीन पर चलती है। यदि एजेंट दूरस्थ मॉडल का उपयोग करता है, तो एजेंट की फ़ाइल सामग्री को संभालने और कमांड परिणाम निर्धारित करते हैं कि उस प्रदाता को क्या भेजा जाता है। वही [PolyForm Shield लाइसेंस](licenses.md) एजेंट संचालित उपयोग पर लागू होता है।

<a id="tool-options"></a>
## टूल के विकल्प

QR पीढ़ी, vCard/Wi-Fi विन्यास, छवि स्कैनिंग और रिवर्स डिकोडिंग में दस्तावेज किए जाते हैं [QR कोड गाइड](qrcode.md). स्थापित करें `qrcode` अतिरिक्त, फिर उपयोग करें `onekit run text-to-qrcode input.txt -o code.png` या `onekit run scan-qrcode photo.jpg -o decoded.json`.

पृष्ठ एक आधारित हैं। `pages` संख्याओं और आरोही श्रेणियों को स्वीकार करता है, जैसे कि `1,3-5`। ऑर्डरिंग और इरादेय डुप्लिकेट को व्यवस्थित / निकालने के लिए संरक्षित किया जाता है। रोटेशन 90 के गुणांक को स्वीकार करता है और सभी पृष्ठों पर चूक करता है। PDF संपादन में `text` से `page` को निचले-बाएँ मूल बिंदु से `x`/`y` PDF अंक शामिल हैं; यह मौजूदा सामग्री को फिर से प्रवाहित नहीं करता है। हस्ताक्षर करने के लिए एक PKCS#12 `certificate` पथ और इसके `password` की आवश्यकता होती है।

छवि `format` PNG, JPEG, WebP, TIFF, BMP, ICO, GIF और PDF का समर्थन करता है। `quality` 1-100 है। `box` पिक्सेल में `[left, top, right, bottom]` है। एनिमेशन / मेटाडाटा हटाया जा सकता है; पारदर्शिता JPEG/PDF के लिए सफेद करने के लिए flattened है। संपीड़न पहले से ही अनुकूलित फ़ाइल को बढ़ा सकता है।

स्प्रेडशीट `sheet` एक कार्यपत्रक का चयन करता है, जो सक्रिय कार्यपत्रक को डिफ़ॉल्ट बनाता है। Excel रीडिंग कैश्ड फ़ॉर्मूला मानों का उपयोग करता है। JSON-to-Excel वस्तुओं की एक सरणी की उम्मीद है। CSV `delimiter` डिफ़ॉल्ट रूप से अल्पविराम के लिए। सूत्र की तरह XLSX स्ट्रिंग्स पाठ रहते हैं; CSV को स्प्रेडशीट अनुप्रयोगों में टेक्स्ट के रूप में आयात करें।

एन्कोडिंग रूपांतरण `source_encoding` और `encoding` को स्वीकार करता है। अन्य पाठ उपकरण UTF-8. का उपयोग PDF, JPEG और PNG के लिए करते हैं, `metadata` वर्णनात्मक टेक्स्ट फ़ील्ड्स `Title`, `Author`, `Subject`, `Keywords` और `Comment` को स्वीकार करता है। अनिर्दिष्ट क्षेत्रों को बनाए रखा जाता है; एक खाली स्ट्रिंग क्षेत्र के मूल्य को साफ़ करती है। Python हेल्पर `onekit.tools.file_metadata.read_metadata(artifact)` ने कलाकृति को संशोधित किए बिना उन क्षेत्रों को पढ़ा, जिसमें समर्थित EXIF, PNG टेक्स्ट और XMP मान शामिल हैं। अन्य मेटाडाटा प्रारूप इसके स्वरूप कवरेज के भीतर वैकल्पिक ExifTool टैग/मूल्य जोड़े का उपयोग करते हैं। इंस्पेक्टर हस्ताक्षर हर मालिकाना फ़ाइल प्रकार की पहचान नहीं करते हैं।

नोटबुक तुलना `mode` `both`, `markdown` या `code` है। LaTeX मोड `all` या heuristic `text` है। PDF/Word तुलना पाठ निकालता है। Diff JSON में सामान्यीकृत पक्ष, परिवर्तित ब्लॉक और एक एकीकृत पैच शामिल है जिसमें ट्रेलिंग-न्यूलाइन अंतर शामिल है। OCR `language` स्थापित Tesseract कोड का उपयोग करता है और `dpi` 36-300 है। PDF/A रूपांतरण के लिए लाइसेंस प्राप्त `icc_profile` की आवश्यकता होती है; स्वतंत्र रूप से आर्किवल आउटपुट को मान्य करें।

मीडिया विकल्पों में `format`, `codec` और `bitrate` शामिल हैं, जो FFmpeg के निर्माण पर निर्भर करता है। फ़ॉन्ट्स `ttf`, `otf`, `woff` और `woff2` का समर्थन करते हैं, रूपरेखा प्रौद्योगिकी को संरक्षित करते हैं। अभिलेखागार समर्थन ZIP और TAR/gzip/bzip2/xz संयोजन।

<a id="limits-and-errors"></a>
## सीमाएँ और त्रुटियाँ

[input मान्यता](input-validation.md) लागू प्रति उपकरण प्रकार, बाइट / काउंट सीमा, हस्ताक्षर / कंटेनर चेक और संग्रह विस्तार नियमों के लिए देखें। ये प्रत्यक्ष Python API कॉल और हर पाइपलाइन चरण के साथ-साथ CLI पर लागू होते हैं। सटीक मशीन पठनीय अनुबंधों के लिए `onekit list --json` रन करें।

कोर इनपुट: 256 फाइलें और 128 MiB। पाइपलाइन: 16 चरणों। चित्र/लेखित पृष्ठ: 40 मिलियन पिक्सेल। तुलना: 10,000 रेखाएं और 2 मिलियन वर्ण। पुरालेख विस्तार: 128 MiB, 4096 प्रविष्टियों और अनुपात चेक। बाह्य इंजनों में टाइमआउट होते हैं। बड़े वैध इनपुट इन जानबूझकर सीमाओं से अधिक हो सकते हैं।

एक्सिट कोड: 0 सफलता; 1 अधूरा डॉक्टर रिपोर्ट; 2 इनपुट/प्रोसेसिंग त्रुटि; 130 रद्दीकरण। वैलिडेटर सफलतापूर्वक `valid: false` का उत्सर्जन कर सकते हैं: निकास 0 के बजाय रिपोर्ट का निरीक्षण करने का मतलब मान्य स्रोत है। टाइप/आयात जाँच को पूरी परियोजना की आवश्यकता हो सकती है। Python वाक्यविन्यास कभी भी इनपुट को निष्पादित नहीं करता है।

अंग्रेजी डिफ़ॉल्ट है। फ्यूचर CLI अनुवादों में `onekit/locales` के तहत गेटटेक्स्ट डोमेन `onekit` का उपयोग किया जाता है; आईडी, कमांड नाम और JSON कुंजी भाषा-स्वतंत्र रहते हैं।

नोटबुक मर्ज स्वीकार करता है `merge` साथ `from` (`left` या `right`) और शून्य-आधारित परिवर्तित सेल `block` सूचकांक, साथ में `mode`. यह अद्यतन लक्ष्य नोटबुक का उत्सर्जन करता है और कोशिकाओं और नोटबुक मेटाडाटा को बाहर रखता है। एकीकृत पैच तुलना में प्रतिनिधित्व का वर्णन करते हैं और आम तौर पर कच्चे के लिए पैच नहीं होते हैं PDF, Word या नोटबुक कंटेनर।

<a id="image-effects"></a>
## चित्र प्रभाव

`onekit run image-effects photo.jpg --options '{"effect":"pixelate","strength":16}' -o output` एक उपकरण में ब्लर, पिक्सेलेशन, बॉक्स ब्लर, सॉलिड कवर और ग्रेस्केल को जोड़ती है। विशिष्ट क्षेत्रों को लक्षित करने के लिए सामान्यीकृत आयताकार `regions` के साथ `scope: "selected"` का उपयोग करें। सभी विकल्पों और सीमाओं के लिए [image प्रभाव गाइड](image-effects.md) देखें।

<a id="portable-workflows"></a>
## पोर्टेबल वर्कफ़्लो

`onekit workflow export SOURCE -o workflow.1kit` एक विरासत चरणों सरणी या एक वर्कफ़्लो दस्तावेज़ को मान्य करता है और एक पोर्टेबल दस्तावेज़ बचाता है। `onekit workflow import workflow.1kit -o saved.1kit` एक आयातित दस्तावेज़ को मान्य और सहेजता है। दोनों आदेशों को omit पासवर्ड और मौजूदा आउटपुट पथ से इनकार करते हैं जब तक कि `--force` की आपूर्ति नहीं की जाती है। न तो आज्ञा प्रक्रिया फ़ाइलों को संसाधित करता है।

`onekit pipeline --steps saved.1kit INPUTS -o OUTPUT` के साथ एक आयातित वर्कफ़्लो चलाएं। .1kit एक्सटेंशन OneKit दस्तावेजों की पहचान करता है; विरासत .json और .onekit.json वर्कफ़्लो फ़ाइलों और चरणों सरणी समर्थित रहे हैं। वर्कफ़्लो दस्तावेज़ UTF-8 JSON हैं, जिनका आकार अधिकतम 1 MiB है, निम्नलिखित संरचना के साथ:

```json
{
  "format": "onekit-workflow",
  "version": 1,
  "steps": [{"tool": "dev-format-json", "options": {}}]
}
```

<a id="automatic-setup"></a>
## स्वचालित सेटअप

`onekit run`, `onekit download` और `onekit pipeline` ने प्रोसेसिंग से पहले लापता Python पैकेज और मूल इंजन स्थापित किया। सिस्टम Python स्थापना को बदलने के बिना उपयोगकर्ता OneKit कैश में निर्भरता रखी जाती है। व्हिस्पर और U2Net मॉडल पहले उपयोग पर स्वचालित रूप से डाउनलोड करते हैं और बाद में रनों के लिए कैश किए जाते हैं। OCR भाषा डेटा अनुरोधित भाषाओं के लिए प्राप्त किया जाता है।

पहले रन में एक इंटरनेट कनेक्शन और पर्याप्त डिस्क स्थान की आवश्यकता होती है। मूल इंजन एक निजी माइक्रोम्बा स्थापना के माध्यम से कोंडा-फोर्ज का उपयोग करते हैं, या इंजन के लिए सिस्टम पैकेज मैनेजर वहां अनुपलब्ध है; उपलब्धता ऑपरेटिंग सिस्टम और आर्किटेक्चर पर निर्भर करती है। सेटअप विफलताओं को त्रुटि के साथ प्रसंस्करण बंद कर दिया जाता है और इसे पुनर्प्राप्त किया जा सकता है। `onekit doctor` कुछ भी स्थापित किए बिना तत्परता की जांच करता है। `ONEKIT_CACHE` सेटअप कैश स्थान बदलता है। `ONEKIT_ALLOW_COPYLEFT=0` प्रतिबंधित इंजनों को ब्लॉक करना जारी रखता है।

<a id="local-license-and-copyright-estimates"></a>
## स्थानीय लाइसेंस और कॉपीराइट अनुमान

`licenses` समूह `license-pdf`, `license-word`, `license-powerpoint`, `license-excel`, `license-video`, `license-audio`, `license-image`, `license-font`, `license-epub`, `license-code` और `license-dataset` प्रदान करता है।

```sh
onekit run license-image photo.jpg -o report.json
onekit run license-pdf --url https://example.org/document.pdf -o report.json
onekit run license-code project.zip -o report.json
onekit run license-code ./project -o report.json
onekit run license-code --url https://github.com/owner/repository --options '{"ref":"main"}' -o report.json
onekit run license-code --url https://gitlab.com/group/project -o report.json
onekit run license-dataset data.csv LICENSE metadata.json -o report.json
```

** हर परिणाम मैनुअल सत्यापन की आवश्यकता के लिए एक असत्यापित अनुमान है।* यह सूची में मेटाडाटा, कॉपीराइट नोटिस, निर्माता नाम, SPDX वाक्यविन्यास और उनके स्थान के साथ टेंटेटिव लाइसेंस-पाठ मैच घोषित किए गए हैं। यह कभी स्वामित्व को प्रमाणित नहीं करता है या किसी काम का उपयोग करने की अनुमति देता है। मिसिंग घोषणाओं का मतलब सार्वजनिक डोमेन या उपयोग करने के लिए स्वतंत्र नहीं है। निर्माता नाम कॉपीराइट स्वामित्व साबित नहीं करते हैं। मूल स्रोत, पूर्ण नियम और इच्छित उपयोग की समीक्षा करें; परियोजना निर्भरता और परिसंपत्तियों में अलग लाइसेंस हो सकते हैं। आधिकारिक संदर्भ मानकों को समझाते हैं, न कि किसी अपलोड किए गए कार्य में घोषणाओं की प्रामाणिकता या प्रयोज्यता।

<a id="downloads-image-transforms-and-url-inspection"></a>
## डाउनलोड, चित्र परिवर्तन और URL की जाँच

```sh
onekit run audio-download --url 'https://example.org/audio.flac' -o downloads/
onekit run audio-download --url 'https://example.org/audio.wav' --options '{"format":"mp3","quality":"320"}' -o downloads/
onekit run image-download --url 'https://example.org/photo.jpg' -o downloads/
onekit run image-rotate-flip photo.png --options '{"angle":"90","flip":"horizontal"}' -o rotated.png
onekit run url-inspect --url 'https://example.org/path?x=1#section' -o report.json
```

एक छवि या ऑडियो फ़ाइल डाउनलोड करने से पुनर्वितरण या अधिकारों का पुन: उपयोग नहीं होता है।

छवि रोटेशन पहले EXIF अभिविन्यास लागू होता है, दक्षिणावर्त 0/90/180/270 डिग्री तक घूमता है, फिर घुमाए गए समन्वय प्रणाली में क्षैतिज रूप से, लंबवत या दोनों को प्रतिबिंबित करता है। यह मेटाडाटा के बिना डिकोडेड RGBA पिक्सल और पारदर्शिता को संरक्षित करने वाला एक PNG निर्यात करता है; एनिमेटेड और बहुपृष्ठ छवियों को अस्वीकार कर दिया जाता है। सीमा 40 मिलियन पिक्सेल है।

<a id="remove-text-formatting"></a>
### टेक्स्ट का फ़ॉर्मैट हटाएँ

`onekit run text-strip-formatting document.docx -o plain.txt` Word बॉडी टेक्स्ट को UTF-8 TXT के रूप में निर्यात करता है। TXT, HTML और Markdown फ़ाइलों को भी समर्थन दिया जाता है, 8 MiB तक। TXT फ़ाइल में संग्रहीत HTML की व्याख्या करने के लिए `--options '{"input_format":"html"}'` का उपयोग करें। कोई OCR नहीं किया जाता है।
