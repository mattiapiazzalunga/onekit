# एंड्रॉयड पैकेज और स्वत: चेहरा धुंधला

पैकेज एक स्टैंडअलोन एपीके और इसके मेटाडाटा को XAPK संग्रह में फिर से लिखने के बिना APK बाइट्स। स्प्लिट APK को खारिज कर दिया गया है। XAPK-compatible installer की आवश्यकता है; हस्ताक्षर सत्यापित नहीं किए जाते हैं।

मूल APKs और OBB डेटा को फिर से लिखने के बिना APK बाइट्स निकालें। स्प्लिट APK एक साथ स्थापित किया जाना चाहिए; वे एक सार्वभौमिक APK में विलय नहीं कर रहे हैं। हस्ताक्षर सत्यापित नहीं हैं।

यूनेट के साथ स्थानीय रूप से चेहरे का पता लगाता है और उन्हें एक ताजा PNG में धुंधला करता है। साझा करने से पहले प्रत्येक चेहरे की समीक्षा करें: स्वचालित पहचान चेहरों को पहचानने में चूक सकती है और ब्लर गुमनामी की गारंटी नहीं देता है। सिंगल-फ्रेम छवियां, 16 मिलियन पिक्सेल तक।

PNG आउटपुट omits स्रोत मेटाडाटा। जब कोई चेहरा पता नहीं लगाया जाता है तो कोई छवि निर्यात नहीं की जाती है।

```sh
onekit run apk-to-xapk app.apk -o app.xapk
onekit run xapk-to-apk app.xapk -o extracted/
onekit run image-blur-faces photo.jpg -o blurred.png
```

स्थानीय फेस डिटेक्शन के लिए वैकल्पिक `faces` अतिरिक्त स्थापित करें।
