# PDF वॉटरमार्क

PDF श्रेणी में, एक PDF अपलोड करें, पाठ दर्ज करें और अस्पष्टता, रंग, फ़ॉन्ट, रोटेशन और स्थिति को समायोजित करें। पूर्वावलोकन एक चयनित पृष्ठ पर वॉटरमार्क स्थिति को दर्शाता है। अंतिम PDF फ़ॉन्ट प्रतिपादन का निरीक्षण करने के लिए निर्यात करें। एक सिंगल वॉटरमार्क या एक बार 3 × 4 ग्रिड चुनें। पृष्ठ या सेल को फिट करने के लिए आवश्यक होने पर पाठ स्वचालित रूप से कम हो जाता है, जिसमें छह-पॉइंट लेगिबिलिटी लिमिट होती है। एन्क्रिप्टेड PDF को पहले अनलॉक किया जाना चाहिए। मौजूदा डिजिटल हस्ताक्षर अब एक दस्तावेज़ को संशोधित करने के बाद सत्यापित नहीं होते हैं; जब हस्ताक्षर क्षेत्र मौजूद होते हैं तो उपकरण चेतावनी देता है।

```sh
onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"CONFIDENTIAL","pages":"1,3-5","opacity":0.25,"angle":45}'
onekit run pdf-watermark input.pdf -o watermarked.pdf --options '{"text":"DRAFT","layout":"repeat","color":"#b00000"}'
```

| विकल्प | मूल्य / डिफ़ॉल्ट |
| --- | --- |
| `text` | 1-200 वर्ण, पांच लाइनों तक; डिफ़ॉल्ट DRAFT |
| `pages` | एक-आधारित रेंज, उदाहरण के लिए `1,3-5`; खाली या omitted मतलब सभी |
| `font` | Helvetica बोल्ड (डिफ़ॉल्ट), Helvetica, टाइम्स-रोमन, Courier |
| `font_size` | 8-160 अंक; डिफ़ॉल्ट 48, स्वचालित रूप से फिट जब जरूरत |
| `color` | छह-अंक हेक्स; डिफ़ॉल्ट #666666 |
| `opacity` | 0.05-1; डिफ़ॉल्ट 0.25 |
| `angle` | -180-180 डिग्री, काउंटरक्लॉकवाइज; डिफ़ॉल्ट 45 |
| `position` | सेंटर, टॉप-लेफ्ट / सेंटर / राइट, मिडिल-लेफ़ / राइट, बॉटम-लेफ्ट/सेंटर / राइट |
| `layout` | एकल (डिफ़ॉल्ट) या दोहराना (3 × 4 ग्रिड; स्थिति को नजरअंदाज कर दिया गया है) |
| `margin` | 0–144 अंक; डिफ़ॉल्ट 24 |

फ़ॉन्ट्स पश्चिमी यूरोपीय वर्णों और punctuation का समर्थन करते हैं, जिनमें इतालवी उच्चारण शामिल है। अनसमर्थित वर्ण स्पष्ट रूप से विफल हो जाते हैं। 512 पृष्ठों तक संसाधित किया जा सकता है। प्लेसमेंट दृष्टि से उन्मुख क्रॉप बॉक्स का उपयोग करता है, मूल रोटेशन और एनोटेशन निर्देशांक को बनाए रखता है। एक वॉटरमार्क लेबल दृश्य सामग्री; यह अंतर्निहित सामग्री को नहीं हटाता है।
