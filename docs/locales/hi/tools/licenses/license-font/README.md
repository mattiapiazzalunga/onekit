# फ़ॉन्ट का लाइसेंस जाँचें

कमान: `onekit run license-font`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** लाइसेंस* Fidelity: ** compromise* घोषणाओं और मेटाडाटा के आधार पर एक अनुमान, कोई अधिकार प्रमाण पत्र या कानूनी मंजूरी नहीं है। मूल स्रोत और अधिकार धारक के साथ हर खोज को सत्यापित करें। मिसिंग सूचना का मतलब प्रयोग करने के लिए स्वतंत्र नहीं है। लेखक और कॉपीराइट धारक भिन्न हो सकते हैं। स्थानीय रूप से फ़ाइलों का विश्लेषण किया जाता है; लिंक सीधे उनके स्रोत से डाउनलोड किए जाते हैं। अभिलेखागार बाध्य हैं और स्कैन अधूरे हो सकते हैं।

स्वीकृत प्रकार: `ttf, otf, woff, woff2`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** कोई* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `ref`।

Python पैकेज: license-expression, defusedxml, fonttools, brotli। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/license_check.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।
