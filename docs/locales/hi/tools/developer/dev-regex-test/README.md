# रेगुलर एक्सप्रेशन जाँचें

कमान: `onekit run dev-regex-test`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **डेवलपर* Fidelity: ** सटीक* परीक्षण JavaScript नियमित अभिव्यक्तियों के साथ स्थानीय रूप से कब्जा, नामित समूहों, UTF-16 पदों और प्रतिस्थापन। पाठ के 128 KiB तक, 1000 मैच और आउटपुट का 1 MiB। निष्पादन समय सीमित है; CLI को Node.js की आवश्यकता होती है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: **131,072 बाइट्स प्रति फ़ाइल*, **134,217,728 बाइट्स कुल* प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `pattern`, `flags`, `max_matches`, `enable_replacement`, `replacement`.

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाह्य इंजन: node।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/regex_tester.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
