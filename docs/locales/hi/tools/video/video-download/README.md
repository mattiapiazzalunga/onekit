# वीडियो डाउनलोड करें

कमान: `onekit run video-download`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **वीडियो* Fidelity: ** सटीक* यूट्यूब और अन्य yt-dlp साइटों से डाउनलोड, 128 MiB तक। साइट समर्थन भिन्न होता है; एक इंटरनेट कनेक्शन की आवश्यकता होती है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `*`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 16,384 बाइट्स प्रति फ़ाइल*, **134,217,728 बाइट्स कुल* प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `quality`, `cookies`, `cookies_from_browser`, `format_id`, `referer`, `list_formats`.

Python पैकेज: yt-dlp। बाह्य इंजन: ffmpeg।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/video_download.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
