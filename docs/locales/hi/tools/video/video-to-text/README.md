# वीडियो से टेक्स्ट

कमान: `onekit run video-to-text`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **वीडियो* Fidelity: ** compromise* बहुभाषी व्हिस्पर छोटे के साथ स्थानीय रूप से एक वीडियो के ऑडियो को ट्रांसक्रिप्ट करता है। UTF-8 टेक्स्ट और टाइमटाम्प्ड सेगमेंट का निर्यात करें। मान्यता गलतियाँ कर सकती है; यह उपशीर्षक या फ़्रेम में दिखाई देने वाला पाठ नहीं पढ़ता है।

स्वीकृत प्रकार: `mp4, webm, mkv, mov, avi, gif, mpeg, mpg, m4v, ogv, ts`। आउटपुट प्रकार: `txt`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `language`।

Python पैकेज: faster-whisper।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/transcription.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
