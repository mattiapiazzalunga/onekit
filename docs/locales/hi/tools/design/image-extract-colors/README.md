# चित्र के रंग निकालें

कमान: `onekit run image-extract-colors`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** डिजाइन* Fidelity: ** सटीक* एक सीमित छवि नमूने से माध्य-कट प्रमुख रंग। पूरी तरह से पारदर्शी पिक्सल को छोड़कर; आंशिक पारदर्शिता सफेद रंग पर मिश्रित है। रंग भिन्न नमूने का वर्णन करते हैं, कोई शब्दार्थ वस्तु नहीं है।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `colors`।

Python पैकेज: Pillow। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/photo_tools.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
