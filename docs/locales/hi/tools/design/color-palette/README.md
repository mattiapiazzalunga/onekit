# रंग पैलेट बनाएँ

कमान: `onekit run color-palette`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** डिजाइन* Fidelity: ** सटीक* sRGB क्रोमा कमी और WCAG पाठ विपरीत के साथ पांच रंग OKLCH पैलेट। हार्मोनी नियम डिज़ाइन हेरिस्टिक्स हैं, एक्सेसिबिलिटी गारंटी नहीं है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: **128 बाइट्स प्रति फ़ाइल* * * * 1,048,576 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `harmony`, `lightness`, `chroma`, `hue`, `format`.

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/design.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
