# चित्र घुमाएँ और पलटें

कमान: `onekit run image-rotate-flip`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** चित्र* Fidelity: ** सटीक* EXIF अभिविन्यास लागू करें, दक्षिणावर्त 0, 90, 180 या 270 डिग्री तक घुमाएं, फिर क्षैतिज रूप से, लंबवत या दोनों को प्रतिबिंबित करें। मेटाडाटा के बिना एक PNG निर्यात करता है, डीकोडेड पिक्सेल और पारदर्शिता को संरक्षित करता है। केवल सिंगल-फ्रेम छवियां; 40 मिलियन पिक्सेल तक।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `png`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `angle`, `flip`

Python पैकेज: Pillow। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/image_transform.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
