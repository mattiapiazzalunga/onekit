# चित्र संपीड़ित करें

कमान: `onekit run image-compress`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** चित्र* Fidelity: ** compromise* हानिपूर्ण स्वरूप विस्तार को त्याग देते हैं। एनिमेशन और मेटाडाटा को हटाया जा सकता है; पिक्सेल को संरक्षित करने के लिए एक हानिरहित प्रारूप का उपयोग करें।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `image`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 67,108,864 बाइट प्रति फ़ाइल *, **134,217,728 बाइट्स कुल* प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `format`, `quality`

Python पैकेज: Pillow। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/images/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
