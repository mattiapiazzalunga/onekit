# फ़ोटो की खामियाँ ठीक करें

कमान: `onekit run image-repair`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** चित्र* Fidelity: ** compromise* एक मीडियन फ़िल्टर के साथ छोटे धब्बों को साफ करें या हार्मोनिक प्रसार द्वारा चयनित क्षेत्रों का पुनर्निर्माण करें। आसपास के रंगों का अनुमान; छिपी हुई मूल सामग्री को पुनर्प्राप्त नहीं कर सकता और न ही हर फोटोग्राफिक दोष को ठीक कर सकता है। एक नया PNG बचाता है।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `png`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `regions`, `iterations`, `size`

Python पैकेज: Pillow, numpy। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/photo_tools.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
