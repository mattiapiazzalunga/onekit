# चित्र धुंधला करें, पिक्सेल प्रभाव और अन्य प्रभाव लगाएँ

कमान: `onekit run image-effects`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** चित्र* Fidelity: ** compromise* एक उपकरण में ब्लर, पिक्सेलेट, बॉक्स ब्लर, सॉलिड कवर या ग्रेस्केल। संपूर्ण छवि या चयनित क्षेत्रों पर लागू करें, समायोज्य तीव्रता और एक ताजा PNG निर्यात के साथ। ब्लूर और पिक्सेलेशन संवेदनशील विवरणों के स्थायी हटाने की गारंटी नहीं देते हैं। केवल एकल फ्रेम छवियों।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `png`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `effect`, `scope`, `strength`, `color`, `regions`.

Python पैकेज: Pillow। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/image_effects.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
