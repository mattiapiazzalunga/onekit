# चेहरे अपने आप धुंधले करें

कमान: `onekit run image-blur-faces`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** चित्र* Fidelity: ** compromise* यूनेट के साथ स्थानीय रूप से चेहरे का पता लगाता है और उन्हें एक ताजा PNG में धुंधला करता है। साझा करने से पहले प्रत्येक चेहरे की समीक्षा करें: स्वचालित पहचान चेहरों को पहचानने में चूक सकती है और ब्लर गुमनामी की गारंटी नहीं देता है। सिंगल-फ्रेम छवियां, 16 मिलियन पिक्सेल तक।

स्वीकृत प्रकार: `png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `png`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: कोई नहीं।

Python पैकेज: onnxruntime, numpy, Pillow। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/face_blur.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
