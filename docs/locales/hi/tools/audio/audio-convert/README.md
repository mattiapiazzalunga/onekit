# ऑडियो का फ़ॉर्मैट बदलें

कमान: `onekit run audio-convert`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **ऑडियो* Fidelity: ** compromise* उपलब्ध कोडेक आपके FFmpeg बिल्ड पर निर्भर करते हैं; फिर से एन्कोडिंग गुणवत्ता खो सकता है।

स्वीकृत प्रकार: `mp3, wav, flac, ogg, aac, m4a, mp4, aif, aiff, opus, wma`। आउटपुट प्रकार: `*`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `format`, `codec`, `bitrate`

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाह्य इंजन: ffmpeg, ffprobe।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/media/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
