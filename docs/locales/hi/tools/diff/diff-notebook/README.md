# Jupyter नोटबुक फ़ाइलों की तुलना करें

कमान: `onekit run diff-notebook`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** diff* Fidelity: ** सटीक* नोटबुक तुलना में Markdown, कोड या दोनों शामिल हो सकते हैं। LaTeX पाठ मोड omits आदेश।

स्वीकृत प्रकार: `ipynb`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करते हैं: ** * *।

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: **2-2* CLI: ** 8,388,608 बाइट प्रति फ़ाइल* *, **134,217,728 बाइट्स कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `mode`।

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/diff/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
