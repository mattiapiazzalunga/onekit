# PDF का वॉटरमार्क हटाएँ

कमान: `onekit run pdf-remove-watermark`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **pdf** Fidelity: ** compromise* चयनित टेक्स्ट, छवियों और फॉर्म इनवोकेशन का निरीक्षण करें और निकालें, जिसमें घोंसले के रूप और फ़ॉन्ट-एनकोड किए गए पाठ शामिल हैं। स्वचालित रूप से चिह्नित वॉटरमार्क कलाकृतियों और वॉटरमार्क एनोटेशनों को हटा देता है। Untagged ऑब्जेक्ट्स को चयन या सटीक पाठ की आवश्यकता होती है; चपटा निशान उनकी छवि से अलग नहीं किया जा सकता है। प्रत्येक पृष्ठ की समीक्षा करें।

स्वीकृत प्रकार: `pdf`। आउटपुट प्रकार: `pdf`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `text`, `mode`, `objects`
