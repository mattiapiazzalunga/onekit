# PDF में पेज नंबर जोड़ें

कमान: `onekit run pdf-page-numbers`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **pdf** Fidelity: ** सटीक* सभी या चयनित पृष्ठों को अनुक्रमिक संख्या जोड़ता है, स्रोत पाठ और ग्राफिक्स को बनाए रखता है। मौजूदा डिजिटल हस्ताक्षर अमान्य हैं।

स्वीकृत प्रकार: `pdf`। आउटपुट प्रकार: `pdf`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `pages`, `start_number`, `number_style`, `font_size`, `position`, `margin`, `color`.

Python पैकेज: pypdf, reportlab। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/pdf.page_numbers/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
