# भरने योग्य PDF बनाएँ

कमान: `onekit run pdf-make-fillable`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **pdf** Fidelity: ** सटीक* AcroForm टेक्स्ट फ़ील्ड्स, चेकबॉक्सेस और ड्रॉपडाउन विकल्पों को ऊपरी-बाएँ कोने से सामान्यीकृत आयतों का उपयोग करके जोड़ें। मौजूदा क्षेत्रों और पृष्ठ सामग्री रखता है। कोई स्वचालित रिक्त पहचान या XFA रूपांतरण नहीं; रीडर संगतता को सत्यापित करें।

स्वीकृत प्रकार: `pdf`। आउटपुट प्रकार: `pdf`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `fields`।

Python पैकेज: pypdf. बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/pdf_design.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
