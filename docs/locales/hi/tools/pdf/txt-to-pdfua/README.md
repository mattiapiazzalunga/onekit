# पाठ से PDF/UA

कमान: `onekit run txt-to-pdfua`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **pdf** Fidelity: ** सटीक* एक शीर्षक और भाषा के साथ सादे पाठ से PDF/UA-1 टैग किए गए हैं। रिक्त लाइन अलग पैराग्राफ। केवल लैटिन फोंट; पढ़ने के आदेश और अर्थ की समीक्षा करें। स्वचालित जांच मैनुअल अभिगम्यता समीक्षा की जगह नहीं है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `pdf`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 262,144 बाइट्स प्रति फ़ाइल*, ** 8,388,608 बाइट्स कुल* प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `title`, `language`

Python पैकेज: रिपोर्टलैब, pypdf, तकिया। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/pdfua.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
