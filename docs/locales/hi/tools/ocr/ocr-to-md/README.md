# OCR से Markdown

कमान: `onekit run ocr-to-md`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **ocr* Fidelity: ** compromise* मान्यता स्कैन की गुणवत्ता और स्थापित भाषा पैक पर निर्भर करती है। समीकरण और लेआउट मैनुअल सुधार की आवश्यकता हो सकती है।

स्वीकृत प्रकार: `pdf, png, jpeg, webp, gif, bmp, tiff, ico`। आउटपुट प्रकार: `md`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `language`, `dpi`

Python पैकेज: pytesseract, Pillow, pypdfium2, python-docx। बाह्य इंजन: tesseract।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/ocr/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
