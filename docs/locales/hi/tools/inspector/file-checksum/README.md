# चेकसम की गणना करें

कमान: `onekit run file-checksum`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** इंस्पेक्टर* Fidelity: ** सटीक* स्थानीय रूप से SHA-256, SHA-512, SHA-1 या MD5 की गणना करें। एक वैकल्पिक अपेक्षित चेक की तुलना एक फ़ाइल के खिलाफ की जा सकती है। एक चेकसम डिजिटल हस्ताक्षर को सत्यापित नहीं करता है या फ़ाइल सुरक्षा स्थापित करता है।

स्वीकृत प्रकार: `*`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करते हैं: ** * *।

इनपुट सत्यापन: ** कोई* आवश्यक फ़ाइल गणना: * * 1-20* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `algorithm`, `expected`

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/file_checksum.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
