# टेक्स्ट का फ़ॉर्मैट हटाएँ

कमान: `onekit run text-strip-formatting`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** इंस्पेक्टर* Fidelity: ** compromise* पेस्ट किए गए टेक्स्ट, UTF-8/UTF-16 टेक्स्ट फाइल्स, HTML, Markdown या Word DOCX बॉडी टेक्स्ट को स्थानीय रूप से UTF-8 TXT फाइल में बदल दें। पठनीय पाठ और बुनियादी पैराग्राफ / टेबल ब्रेक को बनाए रखते हुए शैलियों, लिंक और मार्कअप को हटा देता है। सादा पाठ साहित्यिक punctuation को संरक्षित करता है। OCR नहीं; DOCX हेडर, पाद लेखों, छवियों और टिप्पणियों को छोड़ दिया जाता है। प्रति इनपुट 8 MiB तक।

स्वीकृत प्रकार: `txt, html, md, docx`। आउटपुट प्रकार: `txt`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** कोई* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 8,388,608 बाइट प्रति फ़ाइल* *, **134,217,728 बाइट्स कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `input_format`।

Python पैकेज: markdown-it-py, defusedxml। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/plain_text.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
