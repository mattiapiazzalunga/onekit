# URL की जाँच करें

कमान: `onekit run url-inspect`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** इंस्पेक्टर* Fidelity: ** compromise* URL घटकों, HTTP स्थिति, अंतिम URL और सीधे अपने डिवाइस से उपलब्ध प्रतिक्रिया शीर्षलेखों का निरीक्षण करें। 10 HTTP तक की रिकॉर्ड्स को रीडायरेक्ट करता है। नेटवर्क विफलताओं एक आंशिक रिपोर्ट छोड़ देते हैं। यह एक फ़िशिंग, मैलवेयर, DNS या स्वामित्व जांच नहीं है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 16,384 बाइट्स प्रति फ़ाइल*, **134,217,728 बाइट्स कुल* प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: कोई नहीं।

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/link_tools.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
