# QR कोड डिकोड करें

कमान: `onekit run reverse-qrcode`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **qrcode* Fidelity: ** सटीक* एक छवि से स्थानीय रूप से QR पेलोड पढ़ता है; रिवर्स संग्रहीत सामग्री को प्रकट करता है, मूल छवि या जनरेटर सेटिंग्स नहीं। कोई लिंक स्वचालित रूप से नहीं खोला जाता है।

स्वीकृत प्रकार: `png, jpeg, webp, bmp, gif`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 16,777,216 बाइट्स प्रति फ़ाइल**, **134,217,728 बाइट्स कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: कोई नहीं।

Python पैकेज: Pillow, zxing-cpp। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/qrcode.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
