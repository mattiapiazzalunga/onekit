# फ़ाइलें या फ़ोल्डर एन्क्रिप्ट करें

कमान: `onekit run security-encrypt`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **सुरक्षा* Fidelity: ** सटीक* AES-256 एन्क्रिप्टेड ZIP, 7-Zip के साथ संगत। फ़ाइल नाम दिखाई देते हैं। पासवर्ड खोने से वसूली असंभव हो जाती है।

स्वीकृत प्रकार: `*`। आउटपुट प्रकार: `zip`। एकाधिक इनपुट स्वीकार करते हैं: ** * *।

इनपुट सत्यापन: ** कोई* आवश्यक फ़ाइल गणना: * * 1-256* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `password`।

Python पैकेज: pycryptodome, stream-zip, stream-unzip। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/security/__init__.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
