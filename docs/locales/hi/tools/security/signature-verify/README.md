# डिजिटल हस्ताक्षर की जाँच करें

कमान: `onekit run signature-verify`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: **सुरक्षा* Fidelity: ** सटीक* स्थानीय रूप से ADES सत्यापन के साथ PDF और CMS हस्ताक्षरों की जाँच करें। अलग हस्ताक्षर मूल फ़ाइल की आवश्यकता होती है। वैकल्पिक रूप से एक हस्ताक्षर साक्ष्य ZIP जोड़ें। मिसिंग ट्रस्ट या रिवोकेशन साक्ष्य एक अनिश्चित परिणाम देता है।

स्वीकृत प्रकार: `*`। आउटपुट प्रकार: `json`। एकाधिक इनपुट स्वीकार करते हैं: ** * *।

इनपुट सत्यापन: ** कोई* आवश्यक फ़ाइल गणना: * * 1–3* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: कोई नहीं।

Python पैकेज: pypdf, asn1crypto, pycryptodome, pyhanko, pyhanko-certvalidator, cryptography, signxml, xsdata. बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/signatures.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
