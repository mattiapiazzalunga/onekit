# PDF से टेक्स्ट

कमान: `onekit run pdf-to-text`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** कन्वर्टर्स* Fidelity: ** compromise* चयन योग्य टेक्स्ट को UTF-8 में एक्सट्रैक्ट करता है, वैकल्पिक रूप से अनुमानित लेआउट को बनाए रखता है। स्कैन को OCR की आवश्यकता होती है; रीडिंग ऑर्डर, टेबल और कॉलम को समीक्षा की जरूरत होती है।

स्वीकृत प्रकार: `pdf`। आउटपुट प्रकार: `txt`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `pages`, `layout`

Python पैकेज: pypdf. बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/pdf_text.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
