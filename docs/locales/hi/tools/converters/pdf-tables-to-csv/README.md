# PDF की तालिकाएँ से CSV

कमान: `onekit run pdf-tables-to-csv`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** कन्वर्टर्स* Fidelity: ** compromise* चयनित पाठ से तालिकाओं का पता लगाता है। स्कैन को OCR की आवश्यकता होती है; जटिल लेआउट, विलय कोशिकाओं और स्तंभ संरेखण के लिए समीक्षा की आवश्यकता होती हैं। Excel प्रति टेबल एक शीट का उपयोग करता है; CSV प्रति तालिका एक फ़ाइल निर्यात करता है।

स्वीकृत प्रकार: `pdf`। आउटपुट प्रकार: `csv`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: **typed* आवश्यक फ़ाइल गणना: * 1-1* CLI: **134,217,728 बाइट्स प्रति फ़ाइल* *, **134,217,728 बाइट कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `pages`।

Python पैकेज: pycryptodome, pypdf. बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/pdf_tables.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
