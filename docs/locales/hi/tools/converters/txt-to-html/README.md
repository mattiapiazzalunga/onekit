# TXT से HTML

कमान: `onekit run txt-to-html`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** कन्वर्टर्स* Fidelity: ** सटीक* बचे हुए सादे पाठ और संरक्षित व्हाइटस्पेस के साथ एक सुरक्षित HTML दस्तावेज़ बनाता है। स्रोत मार्कअप को शाब्दिक रूप से प्रदर्शित किया जाता है, कभी निष्पादित नहीं होता है।

स्वीकृत प्रकार: `txt`। आउटपुट प्रकार: `html`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** एन्कोडेड-टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 8,388,608 बाइट प्रति फ़ाइल* *, **134,217,728 बाइट्स कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: `source_encoding`।

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/text_converters.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
