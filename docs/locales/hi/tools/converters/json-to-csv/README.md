# JSON से CSV

कमान: `onekit run json-to-csv`। इनपुट और आउटपुट तर्कों के लिए `onekit run --help` का उपयोग करें।

श्रेणी: ** कन्वर्टर्स* Fidelity: ** सटीक* XML टेबल बार-बार फ्लैट रिकॉर्ड का उपयोग करते हैं। JSON से XML एक प्रकार की जड़ / वस्तु स्कीमा का उपयोग करके प्रकारों को संरक्षित करता है; XML विशेषताओं का उपयोग @ और पाठ JSON में #text का उपयोग करता है। स्प्रेडशीट सूत्रों का मूल्यांकन नहीं किया जाता है; पहली शीट डिफ़ॉल्ट रूप से प्रयोग की जाती है। रूपांतरण के बाद स्कीमा और मानों की समीक्षा करें।

स्वीकृत प्रकार: `json`। आउटपुट प्रकार: `csv`। एकाधिक इनपुट स्वीकार करता है: ** नहीं*

इनपुट सत्यापन: ** टेक्स्ट* आवश्यक फ़ाइल गणना: * 1-1* CLI: ** 8,388,608 बाइट प्रति फ़ाइल* *, **134,217,728 बाइट्स कुल** प्रसंस्करण से पहले सामग्री जांच चली जाती है। एक फ़ाइल का नाम बदलने के लिए अपने वास्तविक प्रारूप को नहीं बदलता है।

विकल्प: कोई नहीं।

Python पैकेज: मानक पुस्तकालय या बाहरी इंजन। बाहरी इंजन: भाषा एडाप्टर के लिए डेवलपर इंजन मैट्रिक्स देखें।

प्रसंस्करण कार्यान्वयन: [ साझा परिवार एडाप्टर](../../../../../../src/onekit/tools/structured_data.py)। अनुबंध और प्रतिगमन जुड़नार: [tests](../../../../../../tests/test_core.py). इंजन सेटअप और लाइसेंस: [engine गाइड](../../../docs/engines.md)।

यह निर्देशिका `python scripts/tool_docs.py` तक साझा सूची से उत्पन्न होती है। रजिस्ट्री और परिवार एडाप्टर को संपादित करें, प्रतिगमन जुड़नार जोड़ें, फिर निर्देशिका को फिर से उत्पन्न करें।
