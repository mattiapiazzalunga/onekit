# सुरक्षा नीति

संस्करण, मंच, उपकरण, निर्भरता संस्करणों, प्रभाव और कृत्रिम नमूने से समस्या दोहराने के चरणों के साथ निजी तौर पर `security@onekit.org` की रिपोर्ट करें। सार्वजनिक ट्रैकर्स पर संवेदनशील फ़ाइलों, क्रेडेंशियल या शोषण से तैयार निजी रिपोर्ट प्रकाशित न करें। सुधार नवीनतम स्थिर रिलीज को लक्षित करते हैं; कोई प्रतिक्रिया-समय की गारंटी निहित नहीं है।

कोर बाध्य पथ, इनपुट आकार, संग्रह विस्तार, छवि पिक्सेल, तुलना और पाइपलाइनों। एन्क्रिप्शन AES-256-GCM नए नमक/नॉन्स और scrypt के साथ प्रमाणित का उपयोग करता है; खोए हुए पासवर्ड को ठीक नहीं किया जा सकता है। मौजूदा आउटपुट डिफ़ॉल्ट रूप से संरक्षित हैं। इसे क्रियान्वित किए बिना Python मान्यता पार्स स्रोत।

बाहरी कन्वर्टर्स / कंप्यूटर अलग-अलग मूल कार्यक्रम हैं, जो पूरी तरह से सैंडबॉक्स नहीं है। उन्हें अद्यतन रखें और OS नियंत्रण का उपयोग करके शत्रुतापूर्ण दस्तावेजों को अलग करें। CLI एक unauthenticated दूरस्थ रूपांतरण सेवा नहीं है। एक हस्ताक्षरित PDF को संपादित करने से हस्ताक्षर को अमान्य कर सकते हैं; PDF अनुमतियां एन्क्रिप्शन अखंडता के बराबर नहीं हैं।

सामान्य जांच कभी प्रकाशन रहस्य प्राप्त नहीं करना चाहिए। स्थिर टैग की समीक्षा संरक्षित मुख्य प्रतिबद्धताओं की पहचान करते हैं। निर्भरता, लाइसेंस और सुरक्षा विफलता ब्लॉक प्रकाशन। कोई परीक्षण सूट सभी विकृत इनपुट या हमलों से सुरक्षा की गारंटी नहीं देता है।
