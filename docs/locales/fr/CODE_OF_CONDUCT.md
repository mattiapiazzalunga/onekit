# Code de conduite

Accueillez les contributeurs quelles que soient leur origine, identité, expérience ou capacité. Soyez respectueux et concentrez les critiques sur le travail. Fournissez des retours constructifs et réalisables.

Le harcèlement, les menaces, la discrimination, le doxxing, la divulgation d'informations privées, l'attention sexuelle et les interruptions prolongées sont inacceptables dans les espaces de projet. Signalez les problèmes en privé à `hello@mattiapiazzalunga.com`.

Les responsables traitent les rapports discrètement et appliquent des clarifications proportionnées, avertissements, suppression de contenu, restrictions temporaires ou exclusion. La représaille est inacceptable. Les responsables suivent les mêmes standards et divulguent les conflits lorsqu’ils traitent les rapports.
