# Code source ouvert (PolyForm Shield 1.0.0)

Vous pouvez utiliser, modifier et redistribuer le cœur pour des usages autorisés, y compris commerciaux et internes. Vous ne pouvez pas l’utiliser pour fournir un produit ou un service qui concurrence le logiciel ou un produit que le concédant ou ses affiliés proposent en utilisant le logiciel ; les offres gratuites et les différentes plateformes ou interfaces peuvent également concurrencer. Lors du partage de copies, incluez le texte de la licence ou son URL et toutes les lignes d’avis obligatoires fournies avec le logiciel. La licence complète s’applique, y compris ses exceptions pour les produits nouveaux et abandonnés, les termes des brevets et la clause de non-garantie. Ici, « Open Source (PolyForm Shield 1.0.0) » décrit le code publié selon ces termes ; la restriction de non-concurrence signifie qu’il s’agit d’un logiciel dont le code source est disponible plutôt que d’un open source non restreint selon la Définition de l’Open Source.
