Local replacement of LGPL components is permitted. Rebuild the Java adapter
with Maven, supply the modified original JARs, and update dependencies.lock.json
to describe those local replacements. prepare_engine_root.py assembles the
guest; pack_filesystem.py and make_manifest.py author its assets. Use
capture_snapshot.mjs with coldStart authoring to regenerate a snapshot before
processing any user document, then compress_snapshot.mjs, attach_snapshot.py,
chunk_filesystem.py and chunk_snapshot.mjs to regenerate the model and hashes.
The CLI selects this replacement through ONEKIT_DSS_MODEL; a browser host can
select the same model when building its distribution. Existing snapshots must
not be reused after changing JARs: they contain already loaded Java classes.
The above permission covers local changes to the adapter, dependency lock and
build tools necessary for replacement, relinking and debugging of LGPL libraries.
